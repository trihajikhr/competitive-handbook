# Distinct Numbers
## Problem
Diberikan $n$ integer, tugas kita adalah menghitung ada berapa banyak elemen unik yang ada pada susunan integer atau array integer tersebut.

## Solution

Solusinya mudah, kita hanya perlu menggunakan struktur data `set`, dimana struktur data ini memiliki kemampuan untuk hanya menyimpan elemen-elemen unik, atau menghilangkan duplikat dari elemen yang disimpanya.

## Proof of Correctness

> [!TIP]
> Kenapa hanya memasukan data ke dalam struktur `set` sudah cukup untuk menyelesaikan permasalahan?

Struktur data `set` memiliki sifat untuk hanya menyimpan nilai unik. Ketika data baru dimasukan kedalam `set`, namun terdapat data yang sama didalamnya, maka data baru tersebut akan diabaikan. 

Artinya, `set` bisa bekerja sebagai filter untuk hanya menyaring data-data unik, dan mengabaikan data baru yang ternyata sudah dimilikinya. Jadi, pemilihan `set` sangat tepat disini.

> [!TIP]
> Apakah ada alternatif lain selain menggunakan `set`? 

Terdapat alternatif lain yaitu menggunakan struktur data `unordered_set`. Struktur data ini bekerja dengan cara yang sama dengan `set`, yaitu memfilter data unik. Namun perbedaanya adalah struktur data ini tidak mengurutkan data yang disimpanya. Hal ini membuat struktur data `unordered_set` praktis lebih cepat untuk operasi  insert dan searching dengan kompleksitas rata-rata $O(1)$, berbeda dengan `set` biasa yang rata-rata $O(log \; n)$. `unordered_set` sangat cepat secara rata-rata, tapi bisa terkena hash collision yang membuat performanya turun, walaupun biasanya tidak terlalu signifan ke performa keseluruhan.

Masih banyak alternatif lain, namun 2 opsi tersebut merupakan yang terbaik.


## Code Implementation

```cpp
#include <iostream>
#include <set>
using namespace std;

auto main() -> int {
    int n;
    cin >> n;
    set<int> daset;
    for (int i = 0, x; i < n; i++) {
        cin >> x;
        daset.insert(x);
    }

    cout << daset.size();
    return 0;
}
```
