# Ferris Wheel
## Problem

Terdapat $n$ anak yang bepergian ke kereta gondola. Setiap gondola bisa menampung satu atau dua anak. Setiap anak memiliki berat masing-masing $a_i$. Jika untuk setiap gondola, tidak boleh menampung total berat anak yang melebihi $x$, maka tentukan berapa banyak gondola minimal yang dibutuhkan untuk menampung semua anak.

## Solution

Solusi yang bisa digunakan disini adalah dengan mensorting $n$ berat anak-anak secara *descending*. Lalu kemudian melakukan teknik *two pointer*, dimana pointer pertama menunjuk ke elemen urutan pertama, sedangkan pointer kedua menunjuk ke elemen urutan terakhir. Pointer pertama bergerak dari kiri ke kanan, dan pointer terkahir beergerak dari kanan ke kiri.

Intuisi dari cara ini adalah, bahwa elemen yang lebih besar, akan memiliki ruang tersisa yang lebih kecil yang bisa diisi oleh anak lain, sehingga elemen terbesar pasti harus mendapatkaan pasangan yang lebih kecil, dan ini dilakukan dengan 2 pointer, sisi depan dan juga sisi belakang.

Katakanlan array yang menampung ukuran anak-anak tersebut adalah $wei$, pointer yang bergerak dari kiri ke kanan adalah $i$, dan pointer yang bergerak dari kanan ke kiri adalah $back$. Maka, ketika $wei[i] + wei[back] > x$, maka ukuran $wei[i]$ terlalu besar, sampai-sampai elemen terkecil pun (yaitu $wei[back]$) melebihi ruang yang tersisa. Jika hal ini terjadi, maka orang dengan berat $wei[i]$ tersebut akan menggunakan satu gondola khusus untuk dirinya sendiri.

Ketika $wei[i] + wei[back] \le x$, artinya orang dengan berat $wei[i]$ dapat menempati gondola tersebut dengan anak dengan berat $wei[back]$ tanpa melebihi batasan $x$. Ketika ini terjadi, maka nilai $back$ akan di decrement, karena nilai $wei[back]$ sudah digunakan.

Khusus ketika nilai $n$ ganjil, dan semua pasangan berat anak-anak kurang dari $x$, maka akan ada satu anak yang tidak dapat dipasangkan dengan siapapun. Ketika hal ini terjadi, maka anak tersebut otomatis akan menggunakan satu gondola, tanpa pencarian pasangan lain. Pemeriksaan itu bisa dilakukan ketika kedua nilai pointer menunjuk ke elemen yang sama, atau $i \equiv back$.

Berikut implementasinya:

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n, x;
    cin >> n >> x;
    vector<long long> wei(n);
    for (int i = 0; i < n; i++) {
        cin >> wei[i];
    }

    sort(wei.rbegin(), wei.rend());

    int ans = 0, back = n - 1;
    for (int i = 0; i <= back; i++) {
        if (i == back) {
            ans++;
            break;
        }
        if (wei[i] + wei[back] > x) {
            ans++;
        } else if (wei[i] + wei[back] <= x) {
            ans++, back--;
        }
    }

    cout << ans;
    return 0;
}
```
