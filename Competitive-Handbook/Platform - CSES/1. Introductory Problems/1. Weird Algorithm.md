# Weird Algorithm
![](_assets/1.%20Weird%20Algorithm-1.png)

## Problem

Pertimbangkan sebuah algoritma yang menerima masukan berupa bilangan bulat positif $n$. Jika $n$ bernilai genap, algoritma membaginya dengan dua, dan jika $n$ bernilai ganjil, algoritma mengalikannya dengan tiga lalu menambah satu. Algoritma ini mengulangi proses tersebut hingga $n$ bernilai satu. Sebagai contoh, barisan untuk $n = 3$ adalah sebagai berikut: 
$$3 \rightarrow 10 \rightarrow 5 \rightarrow 16 \rightarrow 8 \rightarrow 4 \rightarrow 2 \rightarrow 1$$

Tugasmu adalah mensimulasikan eksekusi algoritma tersebut untuk nilai $n$ yang diberikan.

## Solution

Cukup implementasikan perulangan jenis `while` yang akan terus bekerja ketika $n > 1$, dan lalu lakukan percabangan yang persis diminta oleh soal, yaitu lakukan operasi $n = n/2$ ketika $n$ genap, atau operasi $n = n \times 3 + 1$ ketika $n$ ganjil.

Ketika perulangan berakhir, outputkan $1$ untuk melengkapi deret yang diminta.

## Proof of Correctness

Ini adalah soal tipe implementasi, yang semuanya sudah dijelaskan di pernyataan masalah, sehingga tidak membutuhkan pembuktian apapun.

## Code Implementation

```cpp
#include <iostream>
using namespace std;

auto main() -> int {
    long long n;
    cin >> n;

    while (n > 1) {
        cout << n << " ";
        if (n % 2 == 0) {
            n = n / 2;
        } else {
            n = n * 3 + 1;
        }
    }
    cout << 1;

    return 0;
}
```
