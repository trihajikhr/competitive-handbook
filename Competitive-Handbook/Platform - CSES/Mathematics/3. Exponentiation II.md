# Exponentiation II

Walaupun ini adalah problem yang lebih ditingkatkan dari problem sebelumnya yang lebih mudah, yaitu problem [CSES - Exponentiation](https://cses.fi/problemset/task/1095), namun ada trik lain yang dibutuhkan untuk menyelesaikan problem ini. 

Secara intuitif, mungkin kita bisa menggunakan *Binary Exponentiation* untuk nilai $b^c$, yang kemudian hasilnya kita gunakan untuk menghitung $a^{b^{c}}$ , misal seperti ini (contoh yang salah):

```cpp
#include <iostream>
using namespace std;
 
constexpr long long mod = 1e9 + 7;
 
auto binpow(long long a, long long b) -> long long {
    long long rest = 1;
    while (b > 0) {
        if (b & 1) {
            rest = rest * a % mod;
        }
 
        a = a * a % mod;
        b >>= 1;
    }
    return rest;
}
 
auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        long long a, b, c;
        cin >> a >> b >> c;
        cout << binpow(a, binpow(b, c)) << "\n";
    }
 
    return 0;
}
```

Namun, cara diatas tidaklah tepat. Masalah utama pada kode diatas terletak pada cara kerja modular arithmetic dan sifat eksponensial bertingkat ($a^{b^c}$).

Secara matematis, ini menghitung $a^{(b^c \pmod{10^9+7})}$. Padahal, yang diminta oleh soal adalah $a^{(b^c)} \pmod{10^9+7}$.

Hasil dari $b^c \pmod{10^9+7}$ **tidak sama** dengan hasil aslinya sebelum dimodulo, karena operasi modulo merusak sifat eksponen jika langsung diterapkan pada pangkatnya ($b^c$).

## Fermat's Little Theorem

Untuk menyederhanakan pangkat $b^c$, kita bisa memanfaatkan sifat modulo dari Fermat's Little Theorem. Jika modulo adalah bilangan prima $p$ (dalam hal ini $10^9 + 7$ adalah bilangan prima), maka:

$$a^{p-1} \equiv 1 \pmod{p}$$

Ini berarti, pangkat $b^c$ bisa kita modulo dengan **$p - 1$** ($10^9 + 6$), **bukan** dengan $p$ ($10^9 + 7$).

Sehingga, perhitungannya menjadi:

- Hitung $p_{art} = b^c \pmod{10^9 + 6}$
- Hasil akhir = $a^{p_{art}} \pmod{10^9 + 7}$

Sehingga, hasil akhirnya adalah kita harus menggunakan 2 jenis modulo pembagi, dan mengubah kode sebelumnya sedikit menjadi seperti ini:

```cpp
#include <iostream>
using namespace std;

constexpr long long mod = 1e9 + 7;
constexpr long long mod_phi = mod - 1;

auto binpow(long long a, long long b, long long MOD) -> long long {
    long long rest = 1;
    while (b > 0) {
        if (b & 1) {
            rest = rest * a % MOD;
        }

        a = a * a % MOD;
        b >>= 1;
    }
    return rest;
}

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        long long a, b, c;
        cin >> a >> b >> c;
        cout << binpow(a, binpow(b, c, mod_phi), mod) << "\n";
    }

    return 0;
}
```
