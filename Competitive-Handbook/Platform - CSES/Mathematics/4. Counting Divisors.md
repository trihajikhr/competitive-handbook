# Counting Divisors
Diberikan $n$ query, dengan setiap query diberikan nilai $x$. Tugas kita adalah menghitung ada berapa banyak faktor dari $x$.

Faktor dari $x$ adalah bilangan yang bisa membagi habis $x$. Misal $x=18$, maka jawabanya adalah $6$, karena $18$ bisa dibagi habis oleh angka-angka $1,2,3,6,9,18$.

## Jawaban
Pendekatan naif seperti melakukan perulangan dari $[1,x]$ lalu menghitung berapa saja angka yang bisa membagi habis $x$ memang bisa dilakukan, namun ini jelas tidak efisien dan jelas terkena *Time Limit Exceed*, karena jika jumlah query $n$ besar, dan nilai dari $x$ juga besar, maka kompleksitasnya akan menjadi $O(n \cdot x)$. 

Pendekatan yang lebih efisien adalah dengan mengetahui bahwa banyaknya angka yang bisa membagi habis $x$, sebenarnya bisa diketahui dengan melakukan perulangan sebanyak $\sqrt{x}$ saja.

Kenapa ini berlaku? Karena kita hanya menargetkan faktor-faktor yang bernilai terkecil. Misal $100/2 = 50$, dan $100/50=2$. Daripada melakukan perulangan hingga $50$ untuk mengetahui apakah $x$ bisa dibagi habis olehnya, lebih baik menggunakan nilai $2$ untuk mengetetahui bahwa $100/2 \rightarrow 50$ pun juga bisa membagi habis $100$.

Kita bisa mempercepat pencarian faktor dengan menyadari bahwa faktor dari suatu bilangan selalu berpasangan. Jika $d$ adalah faktor dari $x$ (artinya $x \pmod d = 0$), maka $\frac{x}{d}$ juga merupakan faktor dari $x$.

Algoritmanya adalah sebagai berikut:

1. **Cukup Cek hingga $\sqrt{x}$:**
   Kita hanya perlu melakukan perulangan dari $i = 1$ sampai $\sqrt{x}$.
    - Jika $i$ membagi habis $x$ ($x \pmod i = 0$), maka $i$ adalah faktor.
    - Pasangan dari $i$ adalah $\frac{x}{i}$, yang juga otomatis menjadi faktor dari $x$.

2. **Kasus Khusus (Bilangan Kuadrat Sempurna):** 
   Jika $i = \frac{x}{i}$ (atau dengan kata lain $i \times i = x$), maka $i$ dan $\frac{x}{i}$ adalah angka yang sama. Dalam kondisi ini, kita hanya perlu menghitungnya sebagai satu buah faktor saja agar tidak terjadi duplikasi penghitungan.
    

Berikut adalah implementasi untuk permasalah ini:

```cpp
#include <iostream>
using namespace std;

auto solve(int n) -> int {
    int cnt = 0;
    for (int i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            cnt += 2;
            if ((n / i) == i) {
                cnt--;
            }
        }
    }
    return cnt;
}

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int x;
        cin >> x;
        cout << solve(x) << "\n";
    }

    return 0;
}
```
