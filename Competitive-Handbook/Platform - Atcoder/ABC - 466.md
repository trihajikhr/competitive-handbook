# Compromise

## [A - Compromise](https://atcoder.jp/contests/abc466/tasks/abc466_a)
Mudah saja, cukup lakukan pemeriksaan, apakah salah satu data yang diterima ada yang bukan negatif, atau terdapat kondisi dimana $x \ge 0$. Jika terdapat kondisi seperti ini, maka jawabanya adalah `No`, tapi jika tidak ada satupun angka yang memenuhi kondisi tersebut, maka semua angka pasti negatif, sehingga outputkan `Yes`.

```cpp
#include <iostream>
using namespace std;

auto main() -> int {
    int n;
    cin >> n;
    bool nega = true;
    for (int i = 0, x; i < n; i++) {
        cin >> x;
        if (x >= 0) {
            nega = false;
        }
    }

    cout << (nega ? "Yes" : "No");
    return 0;
}
```

## [B - Representative Balls](https://atcoder.jp/contests/abc466/tasks/abc466_b)

Buat array penampung berukuran $M$, dan tetapkan semua nilainya dengan $-1$. Kemudian, terima pasangan nilai $C_i$ dan $S_i$, lalu perbarui ukuran maksimal dari setiap warna, dengan mencari nilai maksimal dari setiap inputan dengan menggunakan $C_i$ sebagai indexing. Jika menggunakan 0-based index, maka pastikan sesuaikan nilai $C_i$ menjadi $C_i -1$.

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

auto main() -> int {
    int n, m;
    cin >> n >> m;
    vector<int> arr (m, -1);
    for(int i=0; i<n; i++){
        int a, b;
        cin >> a >> b;
        arr[a-1] = max(arr[a-1], b);
    }

    for(const auto& x : arr) {
        cout << x << " ";
    }

    return 0;
}
```

## [C - Count Close Pairs](https://atcoder.jp/contests/abc466/tasks/abc466_c)

Problem interaktif, pastikan sudah belajar tentang problem interaktif sebelumnya!

Problem ini bisa diselesaikan dengan menggunakan algoritma atau pendekatan *sliding window*, memanfaatkan dua pointer $l$ dan $r$ . Dimana dilakukan perulangan pertama dengan menggunakan pointer $l$, dan kemudian pointer $r$ untuk perulangan kedua yang bergerak maju kedepan terus menerus hingga mendapati kondisi dimana judge memberikan `No`. Ketika `No` diberikan, maka artinya nilai dari $r-l$ sudah melebihi $1$, jadi ambil banyaknya pasangan $i,j$ yang selisihnya $\le 1$, dengan cara $r-l$. 

Namun karena nilai `No` diberikan ketika nilai dari $j$ sudah melebihi, maka kurangi lagi dengan $1$, supaya tepat. Sehingga, ketika output `No` diberikan, lakukan akumulasi $r-l-1$.

```cpp
#include <iostream>
using namespace std;

auto main() -> int {
    int n;
    cin >> n;

    int r = 2;
    long long ans = 0;

    for (int l = 1; l < n; l++) {
        if (l == r) {
            r++;
        }
        while (r <= n) {
            cout << "? " << l << " " << r << endl;
            string s;
            cin >> s;

            if (s == "Yes") {
                r++;
            } else {
                break;
            }
        }
        ans += (r - l - 1);
    }

    cout << "! " << ans << endl;
    return 0;
}
```

## [D - Placing Rooks](https://atcoder.jp/contests/abc466/tasks/abc466_d)

Perhatikan batasan dari banyaknya queri $M$, penggunaan array dua dimensi secara langsung akan menyebabkan Time Limit Exceed, karena adanya keharusan untuk melakukan traversal untuk melakukan pengecekan terhadap baris $x$ dan kolom $y$ untuk setiap queri.

Solusinya adalah dengan menggunakan cukup dua arrray berukuran $N$, untuk memetakan apakah terdapat bidak di baris $x$, dan apakah ada bidak di kolom $y$. Misal array tersebut adalah $row$ dan $col$. Setiap baris yang terisi oleh bidak, maka nilainya akan diisi dengan lokasi kolom dimana bidak itu berada. Dan untuk setiap kolom yang terisi bidak, nilai arraynya akan diisi dengan lokasi baris dimana bidak tersebut ada. Sehingga kondisi $row[x] = y$ dan $col[y] = x$ berlaku.

Tetapkan kedua array tersebut dengan $0$, karena ketika program pertama kali berjalan, belum ada bidak yang dimasukan. 

Untuk setiap queri, lakukan pengecekan, apakah baris tersebut sudah terisi atau belum. Jika sudah, array kolom yang menunjuk lokasi baris dimana bidak yang sebelumnya ada harus dihapus, sehingga data kolom harus dibersihkan dengan cara $col[row[x]]=0$. Lakukan pemeriksaan yang sama dengan kolom. Jika kolom terisi, maka hapus lokasi baris yang menunjuk baris dimana bidak sebelumnya berada, dengan $row[col[y]]=0$. 

Setelah itu, tetapkan nilai baru pada dua data tersebut, dengan $row[x]=y$ dan $col[y]=x$.

```cpp
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> row(n + 1, 0), col(n + 1, 0);
    for (int i = 0; i < m; i++) {
        int x, y;
        cin >> x >> y;

        if (row[x]) {
            col[row[x]] = 0;
        }

        if (col[y]) {
            row[col[y]] = 0;
        }

        row[x] = y;
        col[y] = x;
    }

    int cnt = 0;
    for (const auto& x : row) {
        cnt += x ? 1 : 0;
    }

    cout << cnt;

    return 0;
}
```

## Soal E
Misalkan $C_i = B_i - A_i$. Jawaban awal adalah $\sum A_i$. Jika kartu $i$ dibalik dalam kondisi saat ini, jawaban berubah sebesar $C_i$, setelah itu, kontribusinya menjadi $-C_i$.

Dengan demikian, satu operasi pada $[l, r]$ menambahkan $\sum_{i=l}^r C_i$ ke jawaban dan menegasi (mengalikan dengan $-1$) setiap $C_i$ dalam interval tersebut.

Oleh karena itu, kita menggunakan algoritma _greedy_ berikut:

Pilih _subarray_ dengan jumlah maksimum secara berulang, tambahkan jumlahnya ke jawaban, dan negasi _subarray_ tersebut.

Kita berhenti setelah $K$ iterasi, atau lebih awal jika jumlah _subarray_ maksimum bernilai tidak positif.

### Bukti Kebenaran

Untuk sebuah _array_ $C$, misalkan $OPT_k(C)$ adalah keuntungan maksimum yang dapat diperoleh menggunakan paling banyak $k$ operasi.

Urutan dari paling banyak $k$ pembalikan interval ekuivalen dengan memilih gabungan dari paling banyak $k$ interval yang saling lepas (_disjoint_): suatu posisi dipilih tepat ketika posisi tersebut dibalik dalam jumlah ganjil. Oleh karena itu, $OPT_k(C)$ adalah jumlah maksimum dari paling banyak $k$ _subarray_ yang saling lepas.

Misalkan $I=[l, r]$ adalah _subarray_ dengan jumlah maksimum, misalkan $M = \sum_{i \in I} C_i$, dan misalkan $C'$ diperoleh dengan menegasi $C_i$ untuk $i \in I$. Kita mengklaim bahwa:

$$OPT_k(C) = M + OPT_{k-1}(C')$$

Pertama, untuk setiap gabungan $T$ dari paling banyak $k-1$ interval, $T \triangle I$ adalah gabungan dari paling banyak $k$ interval, di mana $\triangle$ melambangkan beda simetris (_symmetric difference_). Lebih lanjut:

$$\sum_{i \in T \triangle I} C_i = M + \sum_{i \in T} C_i'$$

Oleh karena itu, $OPT_k(C) \geq M + OPT_{k-1}(C')$.

Untuk arah sebaliknya, ambil gabungan optimal $S$ dari paling banyak $k$ interval. Karena $I$ adalah _subarray_ dengan jumlah maksimum:

- Setiap prefiks dan sufiks dari $I$ memiliki jumlah non-negatif;
    
- Setiap interval yang langsung memperluas $I$ ke kiri atau kanan memiliki jumlah non-positif.
    

Dengan menggunakan fakta-fakta ini, kita dapat memodifikasi $S$ tanpa mengurangi jumlahnya atau menambah jumlah komponennya sehingga kedua ujung $I$ menjadi batas dari $S$: perluas bagian terpilih di dalam $I$ hingga ke ujung $I$, dan hapus bagian terpilih yang meluas ke luar $I$. Jika $S \cap I$ kosong, masukkan $I$ sebagai gantinya; jika ini menciptakan satu komponen ekstra, hapus komponen lama mana pun, yang jumlahnya paling banyak $M$.

Sekarang $S \triangle I$ memiliki satu komponen lebih sedikit, sehingga ia merupakan gabungan dari paling banyak $k-1$ interval. Juga:

$$\sum_{i \in S} C_i = M + \sum_{i \in S \triangle I} C_i'$$

Jadi, $OPT_k(C) \leq M + OPT_{k-1}(C')$.

Klaim tersebut terbukti. Menerapkannya secara berulang membuktikan bahwa memilih _subarray_ dengan jumlah maksimum saat ini di setiap iterasi adalah optimal.

### Algoritma

1. Tetapkan $C_i = B_i - A_i$ dan inisialisasi jawaban dengan $\sum A_i$.
    
2. Ulangi paling banyak $K$ kali:
    
    - Temukan _subarray_ dengan jumlah maksimum menggunakan algoritma Kadane;
        
    - Berhenti jika jumlahnya tidak positif;
        
    - Tambahkan jumlahnya ke jawaban;
        
    - Negasi setiap elemen dalam _subarray_ yang dipilih.
        
3. Output jawabannya.
    

### Kompleksitas

Setiap iterasi memakan waktu $O(N)$, sehingga total kompleksitas waktu adalah $O(NK)$. Kompleksitas ruang adalah $O(N)$.

```cpp
#include <bits/stdc++.h>
using namespace std;

#define int long long
constexpr int INF = 1e18;

void solve() {
    int n, k;
    cin >> n >> k;
    int s = 0;
    vector<int> a(n + 1);
    
    for (int i = 1; i <= n; i++) {
        int x, y;
        cin >> x >> y;
        s += x;
        a[i] = y - x;
    }
    
    while (k--) {
        vector<int> pref(n + 1);
        for (int i = 1; i <= n; i++) pref[i] = pref[i - 1] + a[i];
        int mx = -INF, ll = -1, rr = -1, mn = 0, mn_l = 1;
        for (int r = 1; r <= n; r++) {
            int now = pref[r] - mn;
            if (now > mx) {
                mx = now;
                ll = mn_l;
                rr = r;
            }
            
            if (pref[r] < mn) {
                mn = pref[r];
                mn_l = r + 1;
            }
        }
        
        if (mx <= 0)
            break;
        s += mx;
        
        for (int i = ll; i <= rr; i++) a[i] = -a[i];
    }
    cout << s << '\n';
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int testcase = 1;
    // cin >> testcase;
    while (testcase--) solve();

    return 0;
}
```
