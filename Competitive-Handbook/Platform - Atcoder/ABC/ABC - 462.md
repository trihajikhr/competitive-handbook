## [A - Secret Numbers](https://atcoder.jp/contests/abc462/tasks/abc462_a)

Mudah saja, kita bisa menggunkaan fungsi `isdigit()` untuk hanya mengambil karakter yang berupa angka dari string yang diberikan. Jangan lupa include kan header `cctype`. Lalu, supaya lebih cepat dan bersih, manipulasi operasi output dengan hanya mengoutputkan karakter yang berupa angka dengan fungsi ini.

```cpp
#include <cctype>
#include <iostream>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    string s;
    cin >> s;
    for (int i = 0; i < (int)s.length(); i++) {
        if (isdigit(s[i])) {
            cout << s[i];
        }
    }

    return 0;
}
```

## [B - Gift](https://atcoder.jp/contests/abc462/tasks/abc462_b)

Gunakan array dua dimensi dengan 1-based index array untuk mempermudah operasi. Kemudian, untuk setiap $A_{i,K_i}$ gunakan nilai tersebut sebagai index untuk menunjuk diposisi berapa data harus ditambahkan, gunakan `push_back()` untuk operasi ini. Ini adalah jenis problem implementasi yang membutuhkan sedikit pemahaman pada penggunaan array dua dimensi yang sederhana.

```cpp
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<int>> gift(n + 1, vector<int>(0));
    for (int i = 1; i <= n; i++) {
        int k;
        cin >> k;
        for (int j = 1; j <= k; j++) {
            int x;
            cin >> x;
            gift[x].push_back(i);
        }
    }

    for (int i = 1; i <= n; i++) {
        cout << gift[i].size() << " ";
        for (int j = 0; j < (int)gift[i].size(); j++) {
            cout << gift[i][j] << " ";
        }
        cout << "\n";
    }

    return 0;
}
```
