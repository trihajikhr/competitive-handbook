# Japanese Student Championship 2026 - Advance - Qualification

## [A - Decisive Battle](https://atcoder.jp/contests/abc464/tasks/abc464_a)
Cukup hitung banyaknya karakter E dan W dari string yang diterima. Setelah itu, lakukan perbandingan, dan outputkan seperti yang diminta oleh soal. Perhitungan karakter sendiri bisa dilakukan dengan menggunakan fungsi bantu seperti `count`, atau dengan melakukan traversal secara manual.

```cpp
#include <algorithm>
#include <iostream>
#include <string>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    string s;
    cin >> s;
    int e = (int)count(s.begin(), s.end(), 'E');
    int w = (int)count(s.begin(), s.end(), 'W');

    cout << (e > w ? "East" : "West");
    return 0;
}
```

## [B - Crop](https://atcoder.jp/contests/abc464/tasks/abc464_b)
Tipe problem implementasi. Yang perlu dilakukan adalah dengan melakukan pengecekan dari atas, bawah, kiri, dan juga kanan, dan melakukan simulasi penghapusan baris-baris atau kolom-kolom paling pinggir dari grid yang diberikan. Penyelesaian bisa dilakukan dengan melakukan 2 kali perulangan, dengan melakukan pengecekan baris atas-bawah dan kolom kanan-kiri secara bersamaan. Ini memanfaatkan tipe data boolean dan pengecekan ganda.

Lakukan pemeriksaan pada nilai grid, dan ketika ditemukan karakter `#`, maka artinya baris atau kolom tersebut tidak bisa dihapus, dan kita ambil nilai baris atau kolomnya.

Setelah itu, simulasikan penghapusan grid, dengan cara melakukan manipulasi pada proses output.

```cpp
#include <iostream>
#include <vector>
using namespace std;

#if __has_include("schematics.hpp")
#include "schematics.hpp"  // IWYU pragma: export
#else
#define debug(...)
#endif

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<char>> grid(n, vector<char>(m));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> grid[i][j];
        }
    }

    int top = 0, bot = 0, lef = 0, rig = 0;
    bool s1 = true, s2 = true;

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (s1 && grid[i][j] == '#') {
                top = i;
                s1 = false;
            }

            if (s2 && grid[n - i - 1][j] == '#') {
                bot = n - i - 1;
                s2 = false;
            }

            if (!(s1 || s2)) {
                break;
            }
        }
    }

    s1 = s2 = true;
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (s1 && grid[j][i] == '#') {
                lef = i;
                s1 = false;
            }

            if (s2 && grid[j][m - i - 1] == '#') {
                rig = m - i - 1;
                s2 = false;
            }
        }

        if (!(s1 || s2)) {
            break;
        }
    }

    debug(top, bot, lef, rig);

    for (int i = top; i <= bot; i++) {
        for (int j = lef; j <= rig; j++) {
            cout << grid[i][j];
        }
        cout << "\n";
    }

    return 0;
}
```

## [C - Plumage Palette](https://atcoder.jp/contests/abc464/tasks/abc464_c)

Ada $N$ burung, dan setiap burung memiliki 2 warna, yaitu $A$ dan $B$, awalnya semua burung ketika di observasi, memiliki warna $A$. Setiap burung juga memiliki jatah waktu $D$, dimana tepat setelah $D$ hari, warna pertama akan pudar, dan berganti menjadi warna $B$. Diberikan $H$ hari, tentukan berapa banyak warna burung berbeda, jika observasi lanjutan dilakukan selama $H$ hari kedepan.

Itu adalah penyederhaan dari soal. Intuisi pertama mungkin kita ingin menyelesaikan soal tersebut dengan menggunakan iterasi $h$ sebanyak $H$, dan melakukan iterasi kedua untuk mengecek ada berapa banyak burung yang memiliki $D_i \le h$. Pendekatan ini buruk, karena akan memakan waktu, dan tidak memenuhi batasan waktu soal, mengingat ukuran $N$ dan $H$ sangat besar, yaitu sekitar $3 \times 10^5$, menyebabkan solusi naif (*brute force*) seperti ini memiliki kompleksitas $O(N \cdot H)$.

Solusinya adalah dengan mengurutkan burung-burung tersebut secara ascending berdasarkan nilai $D$, lalu kemudian menggunakan bantuan struktur data tipe *key-value* seperti `unordered_map` atau `map`. Dilakukan dua perulangan, perulangan pertama adalah menjalankan iterasi sebanyak $H$, dan iterasi kedua menggunakan `while` untuk pemeriksaan pada array.

Iterasi kedua akan menggerakan variabel indexing untuk array burung, dimana iterasi ini akan berlanjut ketika kondisi $bird[idx].D \le h$, dimana $bird[idx].D$ adalah nilai $D$ dari burung saat ini, dan kemudian $idx$ adalah variabel indexing, dan $h$ adalah nilai iterasi perulangan pertama. Didalam perulangan `while` ini, pengubahan nilai data dilakukan.

Jika $D_i \le h$, maka tambahkan warna $B$ pada map sebanyak $1$, dan kurangkan warna $A$ juga sebanyak $1$. Ketika banyaknya $A$ pada map adalah $0$, maka hapus kehadiran $A$ pada map. 

Lalu outputkan ukuran map tersebut, yang mana akan merepresentasikan banyaknya warna saat ini dengan sesuai.

> [!caution]
> Gunakan `reserve()` jika menggunakna struktur data `unordered_map`, untuk mengatasi resize dan rehash pada proses iterasi!

```cpp
#include <algorithm>
#include <iostream>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

#define fi first
#define se second

void solve() {
    int n, h;
    cin >> n >> h;
    vector<pair<int, pair<int, int>>> bird(n);
    unordered_map<int, int> dasmap;
    dasmap.reserve(3 * 1e5);

    for (int i = 0; i < n; i++) {
        cin >> bird[i].se.fi >> bird[i].first >> bird[i].second.second;
        dasmap[bird[i].se.fi]++;
    }

    sort(bird.begin(), bird.end());
    int idx = 0;
    for (int i = 1; i <= h; i++) {
        while (idx < n && bird[idx].fi <= i) {
            dasmap[bird[idx].se.fi]--;
            dasmap[bird[idx].se.second]++;

            if (dasmap[bird[idx].se.fi] == 0) {
                dasmap.erase(bird[idx].se.fi);
            }
            idx++;
        }

        cout << dasmap.size() << "\n";
    }
}

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int t = 1;
    // cin >> t;
    while (t--) {
        solve();
    }
    return 0;
}
```
