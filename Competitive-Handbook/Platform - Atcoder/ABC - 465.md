# AtCoder Beginner Contest 465

## [A - Supermajority](https://atcoder.jp/contests/abc465/tasks/abc465_a)
Problem yang mudah, cukup terima inputan A dan B dengan tipe data double, lalu lakukan pemeriksaan yang sesui seperti problem statement:
$$A > \left(B \times \frac{2}{3}\right)$$
Jika kondisi diatas terpenuhi maka outputkan `Yes`, dan jika tidak, maka outputkan `No`:

```cpp
#include <iostream>
using namespace std;

auto main() -> int {
    double a, b;
    cin >> a >> b;
    if (a > (b * (2.0 / 3.0))) {
        cout << "Yes";
    } else {
        cout << "No";
    }

    return 0;
}
```

## [B - Parking 2](https://atcoder.jp/contests/abc465/tasks/abc465_b)

Lakukan perulangan dari titik $A$ hingga titik $B-1$, dan ketika titik perulangan berada di dalam rentang $[l,r]$, atau $l \le i < r$, maka tambahkan $x$ pada jawaban. Jika berada diluar rentang ini, tambahkan $y$ sebagai biaya pada jawaban.

```cpp
#include <iostream>
using namespace std;

auto main() -> int {
    int x, y, l, r, a, b;
    cin >> x >> y >> l >> r >> a >> b;
    int ans = 0;

    for (int i = a; i < b; i++) {
        if (l <= i && i < r) {
            ans += x;
        } else {
            ans += y;
        }
    }
    cout << ans;
    return 0;
}
```

## [C - Reverse Permutation](https://atcoder.jp/contests/abc465/tasks/abc465_c)

Jika menggunakna pendekatan naif, yaitu melakukan operasi reverse berkali-kali setiap menemukan $s[i] = o$, maka kompleksitas waktu akan menjadi $O(N \times 5 \times 10^5)$, yang jelas akan melewati batasan waktu yang diberikan.

Yang perlu dilakukan adalah dengan menggunakan intuisi bahwa jika semua karakter dari $s$ adalah 'o', maka susunan yang dibuat akan terlihat selang-seling, seperti ditambahkan dari sisi kiri dan kanan secara bergantian seperti berikut:

Ketika $s=ooooo$, susunan angka yang terbentuk adalah sebagai berikut:

```
4 2 1 3 5
```

Untuk menjalankan mekanisme ini, kita bisa menggunakan struktur data `deque`, sehingga penyisipan dibagian depan dan belakang bisa dilakukan dengan cepat. Operasi selang-seling dilakukan setiap bertemu karakter 'o', misal dibantu dengan tipe data `bool`. Lalu ketika karakter 'x' muncul, maka angka yang ditambahkan harus berkebalikan dari sisi yang sedang aktif sekarang, atau kebalikan dari nilai `bool`, namun tidak perlu mengubah nilai `bool` itu sendiri.

Setelah semuanya selesai, output yang ditampilkan juga harus sesuai dengan nilai `bool` terakhir. Karena nilai tersebut menunjukan mana urutan depan dari susunana angka yang telah dibentuk.

```cpp
#include <deque>
#include <iostream>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n;
    string s;
    cin >> n >> s;

    deque<int> dq;
    bool right = true;
    int cur = 1;
    for (int i = 0; i < n; i++) {
        if (s[i] == 'o') {
            right = !right;
        }

        if (s[i] == 'o') {
            if (right) {
                dq.push_front(cur);
            } else {
                dq.push_back(cur);
            }
        } else if (s[i] == 'x') {
            if (right) {
                dq.push_back(cur);
            } else {
                dq.push_front(cur);
            }
        }
        cur++;
    }

    while (!dq.empty()) {
        if (right) {
            cout << dq.front() << " ";
            dq.pop_front();
        } else {
            cout << dq.back() << " ";
            dq.pop_back();
        }
    }

    return 0;
}
```
