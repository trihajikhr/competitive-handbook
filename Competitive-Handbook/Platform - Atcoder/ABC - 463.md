# ABC
## [A - 16:9](https://atcoder.jp/contests/abc463/tasks/abc463_a)

Mudah saja, rasio $16:9$ terjadi ketika kondisi berikut terpenuhi:
$$\frac{x}{16} \equiv \frac{y}{9}$$

```cpp
#include <iostream>
using namespace std;

auto main() -> int {
    double a, b;
    cin >> a >> b;
    a /= 16.0;
    b /= 9.0;

    cout << (a == b ? "Yes" : "No");
    return 0;
}
```

## [B - Train Reservation](https://atcoder.jp/contests/abc463/tasks/abc463_b)

Kita bisa menggunakan kolom target $C$ sebagai titik index, dengan mengurangkan karakter tersebut dengan karakter $A$ (ingat ASCII). Setelah itu, terima string sebanyak $n$ kali, dan lakukan pangecekan, apakah karakter pada titik tersebut adalah karakter $o$ atau tidak. Jika iya, maka artinya ada tempat duduk yang kosong, sehingga outputkan Yes.

```cpp
#include <iostream>
#include <string>
using namespace std;

auto main() -> int {
    int n;
    char c;
    cin >> n >> c;

    bool pass = false;
    int idx = c - 'A';
    for (int i = 0; i < n; i++) {
        string s;
        cin >> s;
        if (s[idx] == 'o') {
            pass = true;
        }
    }

    cout << (pass ? "Yes" : "No");
    return 0;
}
```

## [C - Tallest at the Moment](https://atcoder.jp/contests/abc463/tasks/abc463_c)

Tidak mungkin melakukan pendekatan naif atau *brute force* untuk setiap query yang diberikan. Solusi bisa didapat dengan menggunakan algoritma dengan kompleksitas $O(N \cdot Q \; log \; N)$, yaitu dengan menggunakan *binary search*.

Perlu diketahui disini, bahwa soal tersebut memberikan nilai $L_i$ secara ascending, artinya waktu keluar Takahashi adalah kronologikal, atau urut waktu. Karena sudah urut, maka kita bisa langsung menerapkan aturan sederhana.

Ketika nilai $H_i$ dari setiap orang ascending, maka otomatis nilai maksimal $H$ akan berada di Takahashi terakhir, yaitu $H_N$, sehingga jawaban untuk semua query adalah sama. Jika nilai dari $H_i$ adalah descending, maka setiap satu Takahashi keluar, maka nilai $H$ maksimal akan berganti ke orang di sebelahnya.

Artinya, kita bisa memfilter untuk hanya menerima nilai $H_i$ secara descending, dengan melakukan pemeriksaan pada data yang sudah ada, apakah data lama $> H_i$ yang baru atau tidak. Proses penghapusan ini berguna karena kita tidak peduli dengan nilai yang bukan maksimal, sehingga ketika data lama $\le H_i$, maka data tersebut akan dihapus, dan dimasukan nilai $H_i$ yang baru.

Setelah itu, array hanya akan terisi nilai $H$ descending, dan setiap query bisa diselesaikan dengan $O(log \; n)$ menggunakan `upper_bound`, dengan menggunakan data $L$ sebagai acuan binary search.

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n;
    cin >> n;
    vector<pair<int, int>> takas;
    takas.reserve(n);

    for (int i = 0; i < n; i++) {
        int H, L;
        cin >> H >> L;

        while (!takas.empty() && takas.back().first <= H) {
            takas.pop_back();
        }

        takas.emplace_back(H, L);
    }

    int q;
    cin >> q;
    for (int i = 0, x; i < q; i++) {
        cin >> x;
        auto it = upper_bound(takas.begin(), takas.end(), x,
                              [](int val, const pair<int, int>& p) { return val < p.second; });

        cout << it->first << "\n";
    }

    return 0;
}

```
