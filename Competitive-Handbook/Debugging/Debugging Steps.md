# Pendekatan Umum dalam Debugging

[3.2 — The debugging process – Learn C++](https://www.learncpp.com/cpp-tutorial/the-debugging-process/)

Setelah suatu masalah ditemukan, proses debugging umumnya terdiri dari enam langkah:

1. Temukan akar masalahnya — biasanya berupa baris kode yang tidak bekerja sebagaimana mestinya.
2. Pastikan kamu memahami penyebab masalah tersebut.
3. Tentukan cara untuk memperbaikinya.
4. Perbaiki bagian kode yang menyebabkan masalah.
5. Lakukan pengujian ulang untuk memastikan masalah telah benar-benar diperbaiki.
6. Lakukan pengujian ulang secara menyeluruh untuk memastikan tidak ada masalah baru yang muncul akibat perbaikan tersebut.
