# Maksimum Subarray Sum

## Task

Kamu diberikan sebuah array yang berisi $N$ buah integer. Tugas kamu adalah mencari nilai maksimum dari jumlah subarray yang tidak kosong dari array tersebut. Subarray adalah bagian dari array yang elemen-elemennya berurutan.

### Input

Baris pertama berisi satu buah integer $N$.

Baris kedua berisi $N$ buah integer $a_1, a_2, \dots, a_N$.

### Output

Cetak satu buah integer yang merepresentasikan nilai maksimum dari jumlah subarray yang mungkin.

### Constraints

- $1 \le N \le 2 \cdot 10^5$
    
- $-10^9 \le a_i \le 10^9$
    

### Example Input

```
8
-1 3 -2 5 3 -5 2 2
```

### Example Output

```
9
```

## Jawaban

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

using ll = long long;

auto kadane(const vector<ll>& vec) -> ll {
    ll current_max = vec[0];
    ll global_max = vec[0];

    for (size_t i = 1; i < vec.size(); i++) {
        current_max = max(vec[i], current_max + vec[i]);
        global_max = max(global_max, current_max);
    }
    return global_max;
}

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n;
    cin >> n;
    vector<ll> vec(n);
    for (auto& x : vec) {
        cin >> x;
    }

    ll ans = kadane(vec);
    cout << ans;
    return 0;
}
```
