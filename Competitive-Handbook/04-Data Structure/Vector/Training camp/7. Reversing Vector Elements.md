# Reversing Vector Elements

## Task

Kamu diberikan sebuah `vector` yang awalnya berisi $N$ buah integer. Kamu harus membalik urutan seluruh elemen di dalam `vector` tersebut (elemen pertama menjadi elemen terakhir, elemen kedua menjadi elemen kedua dari terakhir, dan seterusnya). Setelah urutannya dibalik, cetak seluruh isi `vector` tersebut.

### Input

Baris pertama berisi sebuah integer $N$.

Baris kedua berisi $N$ buah integer awal yang dipisahkan oleh spasi.

### Output

Cetak $N$ buah integer yang urutannya sudah dibalik, dipisahkan oleh spasi.

### Constraints

- $1 \le N \le 10^5$
    
- Nilai setiap elemen berada dalam rentang $[-10^9, 10^9]$.
    

### Example Input

```
5
1 2 3 4 5
```

### Example Output

```
5 4 3 2 1
```

## Jawaban

```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

auto main() -> int {
    int n;
    cin >> n;
    vector<int> vec(n);
    for (auto& x : vec) {
        cin >> x;
    }

    for (int i = 0; i < n / 2; i++) {
        swap(vec[i], vec[n - i - 1]);
    }

    for (const auto& x : vec) {
        cout << x << " ";
    }

    return 0;
}
```
