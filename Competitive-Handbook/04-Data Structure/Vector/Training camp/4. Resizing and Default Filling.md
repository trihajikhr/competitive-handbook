# Resizing and Default Filling

## Task

Kamu diberikan sebuah `vector` yang awalnya kosong. Kamu akan menerima $Q$ buah _query_. Setiap _query_ bisa berupa salah satu dari dua jenis berikut:

- `1 x`: Ubah ukuran (_resize_) `vector` menjadi berukuran $x$ elemen. Jika ukuran baru lebih besar dari ukuran saat ini, elemen baru yang ditambahkan harus diinisialisasi dengan nilai `0`. Jika lebih kecil, elemen di bagian belakang akan dipotong.
    
- `2 x y`: Ubah ukuran (_resize_) `vector` menjadi berukuran $x$ elemen. Jika ukuran baru lebih besar, elemen baru yang ditambahkan harus diinisialisasi dengan nilai $y$.
    

Setelah semua _query_ selesai diproses, cetak ukuran akhir dari `vector` beserta seluruh elemen yang tersisa di dalamnya.

### Input

Baris pertama berisi sebuah integer $Q$, yaitu jumlah _query_.

$Q$ baris berikutnya berisi format _query_ seperti yang dijelaskan di atas (diawali dengan angka `1` atau `2`).

### Output

Baris pertama cetak sebuah integer yang menunjukkan ukuran akhir dari `vector`.

Baris kedua cetak seluruh elemen yang ada di dalam `vector` setelah memproses semua _query_, dipisahkan oleh spasi. Jika `vector` kosong, cukup cetak baris baru.

### Constraints

- $1 \le Q \le 10^3$
    
- $0 \le x \le 10^4$
    
- $-10^9 \le y \le 10^9$
    

### Example Input

```
4
1 3
2 5 8
1 2
2 4 -1
```

### Example Output


```
4
0 0 -1 -1
```

**Penjelasan Eksperimen:**

1. `1 3` $\rightarrow$ `vector` di-_resize_ menjadi ukuran 3, diisi default 0: `[0, 0, 0]`
    
2. `2 5 8` $\rightarrow$ `vector` di-_resize_ menjadi ukuran 5, elemen baru diisi 8: `[0, 0, 0, 8, 8]`
    
3. `1 2` $\rightarrow$ `vector` di-_resize_ menjadi ukuran 2, memotong elemen belakang: `[0, 0]`
    
4. `2 4 -1` $\rightarrow$ `vector` di-_resize_ menjadi ukuran 4, elemen baru diisi -1: `[0, 0, -1, -1]`

## Jawaban

```cpp
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    vector<int> vec;
    int q;
    cin >> q;
    while (q--) {
        int t, s, y, prev;
        cin >> t >> s;
        prev = (int)vec.size();

        if (t == 1) {
            vec.resize(s);
            if (s > prev) {
                for (int i = prev; i < s; i++) {
                    vec[i] = 0;
                }
            }
        } else if (t == 2) {
            cin >> y;
            vec.resize(s);
            if (s > prev) {
                for (int i = prev; i < s; i++) {
                    vec[i] = y;
                }
            }
        }
    }

    cout << vec.size() << "\n";
    for (const auto& x : vec) {
        cout << x << " ";
    }

    return 0;
}
```
