# 8. Sorting Vector Elements

## Task

Kamu diberikan sebuah `vector` yang berisi $N$ buah integer. Tugas kamu adalah mengurutkan seluruh elemen di dalam `vector` tersebut secara menaik (_ascending_, dari nilai terkecil hingga terbesar). Setelah diurutkan, cetak seluruh isi `vector` tersebut.

### Input

Baris pertama berisi sebuah integer $N$.

Baris kedua berisi $N$ buah integer yang dipisahkan oleh spasi.

### Output

Cetak $N$ buah integer yang sudah terurut secara menaik, dipisahkan oleh spasi.

### Constraints

- $1 \le N \le 10^5$
    
- Nilai setiap elemen berada dalam rentang $[-10^9, 10^9]$.
    

### Example Input


```
6
5 2 8 1 3 8
```

### Example Output


```
1 2 3 5 8 8
```

## Jawaban

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    int n;
    cin >> n;
    vector<int> vec(n);
    for (auto& x : vec) {
        cin >> x;
    }

    sort(vec.begin(), vec.end());
    for (const auto& x : vec) {
        cout << x << " ";
    }

    return 0;
}
```
