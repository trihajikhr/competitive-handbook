# Vector Initialization and Basic Queries

## Task

Kamu diberikan $N$ buah integer. Tugas kamu adalah memasukkan seluruh integer tersebut ke dalam sebuah `std::vector` secara berurutan. Setelah semua integer dimasukkan, kamu harus mencetak:

1. Jumlah _element_ (ukuran) dari `vector` tersebut.
    
2. Isi dari `vector` tersebut dari indeks pertama hingga terakhir.
    

### Input

Baris pertama berisi sebuah integer $N$.

Baris kedua berisi $N$ buah integer yang dipisahkan oleh spasi.

### Output

Baris pertama cetak sebuah integer yang menunjukkan ukuran dari `vector`.

Baris kedua cetak $N$ buah integer yang berada di dalam `vector` tersebut, dipisahkan oleh spasi.

### Constraints

- $1 \le N \le 10^5$
    
- Nilai setiap integer berada dalam rentang $[-10^9, 10^9]$.
    

### Example Input

```
5
4 7 -2 10 5
```

### Example Output

```
5
4 7 -2 10 5
```

## Jawaban

```cpp
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    int n;
    cin >> n;
    vector<int> vec(n);
    for (int i = 0; i < n; i++) {
        cin >> vec[i];
    }

    cout << vec.size() << "\n";
    for (const auto& x : vec) {
        cout << x << " ";
    }

    return 0;
}
```
