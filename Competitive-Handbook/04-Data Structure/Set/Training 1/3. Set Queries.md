# Set Queries

## Task

Diberikan sebuah barisan yang terdiri dari $N$ buah integer awal. Kamu harus memproses $Q$ buah operasi yang berkaitan dengan kumpulan data terurut. Operasi tersebut dibagi menjadi tiga jenis:

1. **`1 x`**: Menambahkan elemen $x$ ke dalam kumpulan data. Jika elemen tersebut sudah ada, kumpulan data tidak berubah.
    
2. **`2 x`**: Menghapus elemen $x$ dari kumpulan data. Jika elemen tersebut tidak ada, kumpulan data tidak berubah.
    
3. **`3 x`**: Mencari elemen terkecil di dalam kumpulan data yang nilainya **lebih besar atau sama dengan** $x$ ($\ge x$). Cetak nilai elemen tersebut. Jika tidak ada elemen yang memenuhi syarat, cetak `-1`.

Tugas kamu adalah mengeksekusi semua operasi tersebut secara berurutan dan mencetak hasil dari setiap operasi jenis ketiga.

### Input

Baris pertama berisi sebuah integer $N$ yang menyatakan jumlah elemen awal dalam kumpulan data.

Baris kedua berisi $N$ buah integer awal yang dimasukkan ke dalam kumpulan data.

Baris ketiga berisi sebuah integer $Q$ yang menyatakan jumlah operasi.

$Q$ baris berikutnya masing-masing berisi jenis operasi dengan format `1 x`, `2 x`, atau `3 x`.

### Output

Untuk setiap operasi jenis ketiga (`3 x`), cetak nilai elemen yang memenuhi syarat pada baris baru. Jika tidak ditemukan, cetak `-1`.

### Constraints

- $1 \le N, Q \le 2 \cdot 10^5$
- $-10^9 \le x \le 10^9$
- Elemen awal pada kumpulan data juga berada dalam rentang $-10^9$ hingga $10^9$.
    

### Example Input

```
3
1 3 5
4
3 4
1 4
3 4
2 3
```

### Example Output

```
5
4
```

## Editorial

Kita dapat memanfaatkan `std::set` sebagai struktur data utama untuk menyelesaikan permasalahan ini secara efisien. Karakteristik utama dari `set` adalah kemampuannya dalam melakukan penyisipan dan penghapusan elemen secara dinamis, serta menjaga keterurutan data secara otomatis dalam struktur _Self-Balancing Binary Search Tree_.

Untuk menangani kueri pertama dan kedua, kita cukup menggunakan fungsi bawaan `insert` dan `erase` dari `std::set`. Operasi penambahan dan penghapusan elemen ini dapat dieksekusi dengan kompleksitas waktu yang sangat cepat, yaitu secara logaritmik terhadap jumlah elemen yang ada di dalam set.

Untuk menangani kueri ketiga yang meminta pencarian elemen terkecil dengan nilai yang lebih besar atau sama dengan nilai yang diberikan, kita dapat memanfaatkan fungsi anggota `lower_bound`. Fungsi ini akan mencari posisi elemen yang memenuhi syarat tersebut secara langsung dengan kompleksitas logaritmik, tanpa perlu melakukan penelusuran secara linear.

Jika fungsi anggota `lower_bound` mengembalikan _iterator_ yang bernilai sama dengan akhir set, hal ini menandakan bahwa tidak ada elemen yang memenuhi syarat, sehingga kita dapat mencetak `-1`. Sebaliknya, jika _iterator_ tersebut valid, kita dapat langsung mengakses dan mencetak nilai yang ditunjuk oleh _iterator_ tersebut.

> [!CAUTION]
> Perbedaan utama antara fungsi `lower_bound` yang merupakan fungsi anggota (_member function_) dari `std::set` dan fungsi `lower_bound` dari pustaka `<algorithm>` terletak pada cara kerjanya di balik layar.
> 
> Ketika kita menggunakan `std::set`, struktur datanya disimpan dalam bentuk _Self-Balancing Binary Search Tree_ yang tidak mendukung _random access_ (tidak bisa melompati elemen secara langsung). Jika kita menggunakan `std::lower_bound` dari `<algorithm>`, fungsi tersebut akan menganggap wadah data sebagai iterasi linear biasa dan mencoba mencari elemen secara _brute force_ satu per satu, sehingga kompleksitas waktunya menjadi $\mathcal{O}(N)$.
> 
> Sebaliknya, jika kita menggunakan fungsi anggota `daset.lower_bound(b)` milik `std::set`, pencarian akan memanfaatkan struktur _tree_ bawaan dari _set_ itu sendiri untuk melakukan penelusuran secara biner. Hal ini membuat pencarian berjalan jauh lebih cepat dengan kompleksitas waktu logaritmik $\mathcal{O}(\log N)$, sehingga sangat aman dari risiko _Time Limit Exceeded_ pada soal-soal kompetitif.

### Analisis Kompleksitas

- Time Complexity: $\mathcal{O}((N + Q) \log N)$. Setiap operasi penyisipan, penghapusan, dan pencarian batas bawah pada `std::set` membutuhkan waktu $\mathcal{O}(\log N)$. Dengan total $N$ elemen awal dan $Q$ buah kueri, total waktu yang kita butuhkan sangat optimal untuk batasan soal yang diberikan.
    
- Space Complexity: $\mathcal{O}(N + Q_{ins})$ untuk menyimpan elemen-elemen di dalam set, di mana $Q_{ins}$ adalah jumlah elemen baru yang ditambahkan melalui kueri pertama.

## Jawaban

```cpp
#include <iostream>
#include <set>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n;
    cin >> n;
    set<int> daset;
    for (int i = 0, x; i < n; i++) {
        cin >> x;
        daset.insert(x);
    }

    int q;
    cin >> q;
    while (q--) {
        int a, b;
        cin >> a >> b;

        if (a == 1) {
            daset.insert(b);
        } else if (a == 2) {
            daset.erase(b);
        } else if (a == 3) {
            auto it = daset.lower_bound(b);
            if (it == daset.end()) {
                cout << -1 << "\n";
            } else {
                cout << *it << "\n";
            }
        }
    }

    return 0;
}
```
