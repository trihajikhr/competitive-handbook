# Dasar Penggunaan dan Iterasi Terurut

## Task

Diberikan sebuah barisan berisi $N$ bilangan bulat. Kita diminta untuk mencetak seluruh elemen unik dari barisan tersebut secara terurut dari yang terkecil hingga terbesar.

### Input

Baris pertama berisi sebuah integer $N$ yang menyatakan jumlah elemen dalam barisan.

Baris kedua berisi $N$ buah integer yang menjadi elemen-elemen dari barisan tersebut.

### Output

Cetak seluruh elemen unik yang ada pada barisan, diurutkan secara menaik (*ascending*), dipisahkan oleh spasi pada satu baris.

### Constraints

- $1 \le N \le 10^5$
- $-10^9 \le x \le 10^9$

### Example Input

```
6
5 2 8 2 1 8
```

### Example Output

```
1 2 5 8
```

## Editorial

Kita dapat memanfaatkan `std::set` sebagai struktur data utama untuk menyelesaikan permasalahan ini dengan efisien. Karakteristik utama dari `set` adalah kemampuannya dalam menjaga keunikan elemen (_deduplication_) serta mempertahankan keterurutan data secara otomatis.

Ketika kita memasukkan sekumpulan elemen ke dalam `set`, struktur data ini secara otomatis akan:

1. Menyaring duplikasi: Nilai yang sama persis hanya akan disimpan sekali, sehingga kita tidak perlu melakukan pengecekan manual.
    
2. Mengurutkan elemen: Elemen-elemen di dalam `set` selalu terurut secara menaik (_ascending_) berdasarkan nilai kuncinya.

Oleh karena itu, begitu seluruh elemen selesai dimasukkan dan kita melakukan iterasi untuk mencetaknya, nilai-nilai tersebut secara otomatis sudah berada dalam keadaan unik dan terurut dari yang terkecil hingga terbesar.

### Analisis Kompleksitas

- Time Complexity: $\mathcal{O}(N \log N)$. Setiap operasi penyisipan (_insertion_) ke dalam `std::set` (yang diimplementasikan sebagai _Self-Balancing Binary Search Tree_, umumnya _Red-Black Tree_) membutuhkan waktu $\mathcal{O}(\log K)$, di mana $K$ adalah jumlah elemen unik yang sudah ada di dalam set. Untuk $N$ elemen, total waktu yang kita butuhkan adalah $\mathcal{O}(N \log N)$.
    
- Space Complexity: $\mathcal{O}(N)$ untuk menyimpan elemen unik di dalam memori `set`.

## Jawaban

```cpp
#include <iostream>
#include <set>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n;
    cin >> n;
    set<int> daset;
    for (int i = 0, x; i < n; i++) {
        cin >> x;
        daset.insert(x);
    }

    for (const auto& x : daset) {
        cout << x << " ";
    }

    return 0;
}
```
