# Grid Paths I

![](6.%20Grid%20Paths%20I-1.png)

## Problem

Pertimbangkan sebuah *grid* berukuran $n \times n$ yang kotaknya mungkin memiliki jebakan. Anda tidak diperbolehkan melangkah ke kotak yang memiliki jebakan.

Tugas Anda adalah menghitung banyaknya jalur dari kotak kiri-atas ke kotak kanan-bawah. Anda hanya dapat bergerak ke kanan atau ke bawah.

## Solution

Persoalan **Grid Paths** di CSES membawa konsep Dynamic Programming ke dalam ruang dua dimensi (2D Grid) dengan adanya hambatan (*obstacles*).

### 1. Memahami Inti Masalah

Diberikan sebuah petak berukuran $n \times n$. Petak tersebut berisi dua jenis karakter:

* `.` mewakili sel kosong yang bisa dilewati.
* `*` mewakili sel jebakan/hambatan yang tidak bisa dilewati.

Kamu mulai dari sel kiri-atas $(0, 0)$ dan ingin menuju sel kanan-bawah $(n-1, n-1)$. Dari sel manapun, kamu **hanya boleh bergerak ke kanan atau ke bawah**. Tujuannya adalah menghitung banyaknya jalur berbeda dari titik awal ke titik akhir. Karena hasilnya bisa sangat besar, cetak hasilnya dalam modulo $10^9 + 7$.

### 2. Formulasi State DP

* **Definisi State:** $dp[r][c]$ = banyaknya jalur unik dari sel awal $(0, 0)$ menuju sel $(r, c)$.
* **Target:** Mencari nilai dari $dp[n-1][n-1]$.

### 3. Base Case & Inisialisasi

* Jika sel awal $(0, 0)$ adalah jebakan (`*`), maka $dp[0][0] = 0$ (tidak ada jalur sama sekali).
* Jika sel awal $(0, 0)$ adalah sel kosong (`.`), maka $dp[0][0] = 1$.
* Untuk sel jebakan manapun di $(r, c)$, nilai $dp[r][c]$ selalu bernilai $0$.
### 4. Transisi DP (Relasi Rekurens)

Karena pergerakan hanya diizinkan ke **kanan** dan ke **bawah**, maka sel $(r, c)$ hanya bisa dicapai dari dua arah:

1. Dari atas: sel $(r-1, c)$
2. Dari kiri: sel $(r, c-1)$

Berdasarkan aturan penjumlahan combinatorics (*Sum Rule*), total jalur menuju sel $(r, c)$ adalah jumlah jalur dari sel atas ditambah jalur dari sel kiri, selama sel tersebut bukan hambatan:

$$dp[r][c] = (dp[r-1][c] + dp[r][c-1]) \pmod{10^9 + 7}$$

### 5. Strategi Penyelesaian (Bottom-Up)

1. **Inisialisasi Grid:** Buat matriks $dp$ berukuran $n \times n$ diisi nilai $0$.
2. **Set Base Case:** Periksa sel awal. Jika grid $[0][0] == '.'$, set $dp[0][0] = 1$.
3. **Iterasi 2D:** Jalankan perulangan baris $r$ dari $0$ sampai $n-1$, dan perulangan kolom $c$ dari $0$ sampai $n-1$.
4. **Proses Sel:**
	* Jika sel $(r, c)$ adalah hambatan (`*`), biarkan $dp[r][c] = 0$.
	* Jika sel $(r, c)$ kosong (`.`):
		* Tambahkan $dp[r-1][c]$ ke $dp[r][c]$ jika $r > 0$.
		* Tambahkan $dp[c-1]$ (sel kiri) ke $dp[r][c]$ jika $c > 0$.
		* Terapkan operasi modulo $10^9 + 7$.

5. **Output:** Cetak $dp[n-1][n-1]$.

### Efisiensi Ruang (Optimasi Memori)

Karena nilai $dp[r][c]$ hanya bergantung pada baris saat ini dan baris sebelumnya ($r-1$), kamu sebenarnya bisa mengoptimalkan penggunaan memori dari $O(n^2)$ menjadi $O(n)$ menggunakan array 1D berukuran $n$. Namun, menggunakan matriks 2D biasa $O(n^2)$ sudah sangat aman dan efisien untuk $n \le 1000$.
## Proof of Correctness
### Poc 1

> [!TIP]
> Bagaimana formula ini bisa bekerja dengan tepat? 


Berikut adalah Proof of Correctness (PoC) mengapa relasi rekurens pada Grid Paths bekerja dengan sangat presisi.

#### 1. Properti Acyclic dan Topo-Order Alami

Pergerakan yang diizinkan **hanya ke kanan** (menambah indeks kolom $c$) dan **ke bawah** (menambah indeks baris $r$). Struktur ini membentuk sebuah *Directed Acyclic Graph* (DAG).

Artinya, tidak ada siklus (*loop*) yang memungkinkan kamu kembali ke sel yang sudah pernah dilewati. Setiap pergerakan selalu memperbesar nilai $r + c$ (jarak Manhattan dari $(0,0)$). Ini menjamin bahwa untuk menghitung nilai $dp[r][c]$, nilai dari sub-masalah pendukungnya—yaitu $dp[r-1][c]$ dan $dp[r][c-1]$—dijamin sudah terhitung secara permanen dan tidak akan pernah berubah lagi.

#### 2. Sifat Saling Lepas (Disjoint Sets) & Sum Rule

Misalkan $P(r, c)$ adalah himpunan semua jalur valid dari $(0,0)$ menuju sel $(r,c)$.

Setiap jalur yang berakhir di $(r,c)$ pasti memiliki langkah terakhir yang datang dari salah satu dari dua arah:

1. Datang dari sel atas: $(r-1, c) \to (r, c)$
2. Datang dari sel kiri: $(r, c-1) \to (r, c)$

Sebut himpunan jalur yang melalui sel atas sebagai $A$, dan yang melalui sel kiri sebagai $B$.

* Himpunan $A$ dan $B$ bersifat **saling lepas** ($A \cap B = \emptyset$), karena sebuah langkah terakhir tidak mungkin sekaligus datang dari atas DAN dari kiri.
* Gabungan kedua himpunan ini mencakup seluruh jalur yang mungkin ke $(r,c)$, sehingga $P(r,c) = A \cup B$.

Berdasarkan **Aturan Penjumlahan (*Sum Rule*)** dalam kombinatorika, ukuran dari gabungan dua himpunan yang saling lepas adalah jumlah dari ukuran masing-masing himpunan:

$$\vert{}P(r,c)\vert{} = \vert{}A\vert{} + \vert{}B\vert{}$$

Karena memperpanjang jalur dari $(r-1, c)$ ke $(r, c)$ tidak mengubah jumlah jalur unik yang ada (hanya menambah 1 langkah di akhir), maka $\vert{}A\vert{} = dp[r-1][c]$ dan $\vert{}B\vert{} = dp[r][c-1]$. Dari sinilah formula ini diturunkan secara mutlak:

$$dp[r][c] = dp[r-1][c] + dp[r][c-1]$$

#### 3. Penanganan Hambatan (*Obstacles*) secara Matematis

Ketika sebuah sel $(r, c)$ berisi jebakan (`*`), kita menetapkan $dp[r][c] = 0$.

Secara teori himpunan, ini berarti $P(r, c) = \emptyset$ (himpunan kosong, bernilai $0$). Efeknya sangat bersih: ketika sel-sel berikutnya di sebelah kanan $(r, c+1)$ atau di bawah $(r+1, c)$ mencoba mengambil nilai dari sel jebakan ini, mereka akan menjumlahkan angka $0$.

Secara otomatis, semua cabang jalur yang menabrak hambatan akan bernilai $0$ dan tidak akan berkontribusi pada total jalur di sel akhir $(n-1, n-1)$.


#### 4. Pembuktian Induksi Matematika

* **Base Case:** Untuk sel awal $(0,0)$:
	* Jika bernilai `.`, $dp[0][0] = 1$ (terdapat tepat 1 jalur: yaitu diam di titik awal).
	* Jika bernilai `*`, $dp[0][0] = 0$ (jalur terblokir dari awal). Ini terbukti benar.

* **Hipotesis Induksi:** Asumsikan untuk semua sel $(r', c')$ dengan $r' + c' < k$, nilai $dp[r'][c']$ secara akurat menyimpan banyaknya jalur unik dari $(0,0)$ ke $(r', c')$.
* **Langkah Induksi:** Tinjau sel $(r, c)$ di mana $r + c = k$.
	* Sel atas $(r-1, c)$ memiliki $(r-1) + c = k - 1 < k$.
	* Sel kiri $(r, c-1)$ memiliki $r + (c-1) = k - 1 < k$.

	Berdasarkan hipotesis induksi, nilai $dp[r-1][c]$ dan $dp[r][c-1]$ sudah terhitung secara tepat. Karena pergerakan hanya bisa dari atas atau kiri, dan kedua himpunan jalur tersebut saling lepas, maka $dp[r][c] = dp[r-1][c] + dp[r][c-1]$ dijamin menghasilkan jumlah jalur unik yang benar untuk sel $(r,c)$.

Dengan memproses tabel dari baris atas ke bawah dan dari kolom kiri ke kanan, seluruh matriks terisi dengan benar hingga mencapai target $dp[n-1][n-1]$.
## Code Implementation

```cpp
#include <iostream>
#include <vector>
using namespace std;

constexpr int M = 1e9 + 7;

auto main() -> int {
    int n;
    cin >> n;

    vector<vector<char>> grid(n, vector<char>(n));
    vector<vector<int>> dp(n, vector<int>(n, 0));

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            cin >> grid[i][j];
        }
    }

    if (grid[0][0] == '*') {
        cout << 0;
        return 0;
    }

    dp[0][0] = 1;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (i == 0 && j == 0) {
                continue;
            }

            if (grid[i][j] == '*') {
                dp[i][j] = 0;
            } else {
                int A = i - 1 >= 0 ? dp[i - 1][j] : 0;
                int B = j - 1 >= 0 ? dp[i][j - 1] : 0;
                dp[i][j] = (A + B) % M;
            }
        }
    }

    cout << dp[n - 1][n - 1];
    return 0;
}
```
