# Counting Rooms

## Problem
![](1.%20Counting%20Rooms-1.png)
## Solution

> [!CAUTION]
> apa saja materi yang harus dikuasai untuk menyelesaikan permasalah ini?
> 
> * **Basic of Graph**: Memahami konsep dasar representasi graf, termasuk bagaimana grid dua dimensi dapat dipandang sebagai sebuah graf implisit di mana setiap petak bertindak sebagai *node* (simpul) dan hubungan antar petak bertetangga bertindak sebagai *edge* (sisi).
> * **Graph Traversal**: Menguasai teknik penjelajahan graf secara sistematis untuk mengunjungi simpul-simpul yang saling terhubung, khususnya menggunakan algoritma DFS (*Depth-First Search)*.
> * **Graph Grid**: Memahami pemetaan sistem koordinat matriks dua dimensi ke dalam representasi graf serta teknik navigasi arah tetangga (atas, bawah, kiri, kanan) menggunakan *coordinate arrays* (biasanya array `dx` dan `dy`).
> * **Graph Components** (Connected Components): Memahami konsep komponen terhubung untuk mengidentifikasi dan menghitung kelompok wilayah atau ruangan yang terisolasi satu sama lain oleh pembatas (dinding `#`).
> 


Untuk bisa menyelesaikan masalah ini dengan mudah, ketahui terlebih dahulu berbagai macam materi dasar graph, seperti:
- Basic of graph
- Graph traversal
- Graph grid
- Graph components
Jika belum mengetahui hal-hal tersebut, pasti sulit untuk menyelesaikan masalah ini.

Oke, katakanlah kita sudah mengetahui materi-materi dasar tersebut, maka selanjutnya kita bisa membahas penyelesaian.

Simplenya, hal yang perlu dilakukan adalah mengetahui berapa banyak komponen graph dari graph grid yang diberikan. Ruang-ruang yang terpisah tersebut merepresentasikan komponen tersendiri, sehingga hal yang perlu dilakukan adalah melakukan traversal graph dari berbagai titik, dan menandai setiap titik sebagai sudah dikunjungi atau *visited*. 

Jumlah melakukan penelusuran dari berbagai titik berbeda untuk mengunjungi semua titik yang mungkin itulah, yang menjadi jawaban dari permasalahan ini.

Intinya, pelajari 4 materi diatas, dan permasalahan ini akan mudah diselesaikan. Algoritmanya menjadi sebagai berikut:

1. Buat array dua dimensi untuk menampung grid dengan tipe data `char`.
2. Lakukan perulangan untuk menelusuri semua elemen pada grid, dimana jika nilainya adalah karakter titik (`.`) yang artinya petak kosong, maka artinya itu adalah ruang yang bisa dijelajahi, tambahkan satu pada jawaban, dan lakukan penelusuran secara DFS (*Depth first search*) dari sana.
3. Dalam proses DFS, setiap titik yang sudah dikunjungi, harus diberi mark *visited*, sehingga pencarian akan menjadi lebih efisien dan berhenti lebih cepat. 
4. Karena graph grid memiliki node tetangga berupa titik-titik disampingnya, maka gunakan bantuan array koordinat $X$ dan $Y$ untuk mempercepat pencarian ke empat sisi, sehingga bisa memanfaatkan perulangan.
5. Gunakan kondisional untuk memastikan koordinat yang digunakan tetap valid, seperti tidak keluar dari ukuran grid. Pastikan juga untuk hanya menelusuri titik-titik grid yang masih berupa petak kosong (karakter titik (`.`)).

## Proof of Correctness

> [!TIP]
> Kenapa algoritma ini benar dan efisien?


Masalah *Counting Rooms* pada dasarnya meminta kita untuk menghitung jumlah *Connected Components* (komponen terhubung) pada sebuah *graph grid*.

* Setiap petak kosong (`.`) yang belum dikunjungi dan dijadikan titik awal DFS menjamin adanya satu komponen ruangan baru yang terisolasi.
* Proses DFS secara rekursif atau iteratif akan menelusuri seluruh petak yang saling terhubung ke segala arah (atas, bawah, kiri, kanan) sampai batas dinding (`#`) tercapai, memastikan seluruh petak dalam satu ruangan yang sama tersapu bersih dalam satu kali eksekusi penelusuran.

> [!TIP]
> Kenapa aman secara kompleksitas waktu dan memory?


* **Kompleksitas Waktu $\mathcal{O}(N \times M)$:** Setiap petak pada grid berukuran $N \times M$ maksimal hanya dikunjungi dan ditandai sebagai `visited` sekali sepanjang umur program, baik saat pengecekan di fungsi utama maupun saat proses DFS berjalan. Tidak ada petak yang diproses berulang kali.
* **Kompleksitas Ruang $\mathcal{O}(N \times M)$:** Penggunaan memori didominasi oleh penyimpanan grid dua dimensi, array `visited` (atau modifikasi langsung pada grid), serta *call stack* rekursi DFS di memori yang kedalaman maksimumnya dibatasi oleh jumlah petak dalam satu ruangan terpanjang.
* **Penggunaan *Coordinate Arrays* (`dx` dan `dy`):** Memungkinkan pengecekan empat arah tetangga dilakukan secara ringkas melalui perulangan cepat tanpa percabangan if-else yang panjang dan berisiko *human error*, menjaga kode tetap bersih, optimal, dan mudah dieksekusi oleh *compiler*.

> [!TIP]
> Jadi, problem ini cukup mengandalkan pemahaman basic tentang graph?

Betul sekali, masalah ini sepenuhnya dapat diselesaikan dengan mengandalkan pemahaman dasar mengenai graf, khususnya bagaimana mengubah representasi grid matriks menjadi graf implisit dan menerapkan penelusuran *connected component* menggunakan DFS.

## Code Implementation

```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<int> korX = {0, 1, 0, -1};
vector<int> korY = {-1, 0, 1, 0};
using VVC = vector<vector<char>>;

void count_room(VVC& grid, int n, int m, int x, int y) {
    grid[x][y] = '#';

    for (int i = 0; i < 4; i++) {
        int nx = x + korX[i];
        int ny = y + korY[i];

        if ((nx < 0) || (nx >= n) || (ny < 0) || (ny >= m)) {
            continue;
        }

        if (grid[nx][ny] == '#') {
            continue;
        }

        count_room(grid, n, m, nx, ny);
    }
}

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n, m;
    cin >> n >> m;

    vector<vector<char>> grid(n, vector<char>(m));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> grid[i][j];
        }
    }

    int ans = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (grid[i][j] == '.') {
                ans++;
                count_room(grid, n, m, i, j);
            }
        }
    }

    cout << ans;

    return 0;
}
```
