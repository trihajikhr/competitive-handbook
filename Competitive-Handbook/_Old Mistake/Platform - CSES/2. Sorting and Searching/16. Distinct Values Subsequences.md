# Distinct Values Subsequences

## Problem
Diberikan sebuah *array* yang terdiri dari $n$ bilangan bulat, hitung jumlah *subsequence* di mana setiap elemennya bernilai unik.

Sebuah *subsequence* adalah urutan elemen *array* dari kiri ke kanan yang boleh memiliki celah (loncat-loncat).

## Code Implementation

```cpp
#include <bits/stdc++.h>

#ifdef LOCAL
#include "schematics.hpp"
static_assert(schematics::invariant);
#else
#define debug(...)
#endif

using namespace std;
constexpr long long M = 1e9 + 7;

void solve() {
    int n;
    cin >> n;

    map<int, long long> dasmap;
    for (int i = 0, x; i < n; i++) {
        cin >> x;
        dasmap[x]++;
    }

    long long sum = 1;
    for (const auto& [key, val] : dasmap) {
        sum = (sum * (val + 1)) % M;
    }

    cout << sum - 1;
}

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int t = 1;
    // cin >> t;
    while (t--) {
        solve();
    }
    return 0;
}
```
