# Permutations

![](5.%20Permutations-1.png)

## Problem

Permutasi dari bilangan bulat $1, 2, \ldots, n$ disebut *indah* jika tidak ada dua elemen yang bersebelahan yang selisihnya adalah $1$.

Diberikan $n$, susunlah sebuah permutasi yang indah jika permutasi tersebut memang ada.

## Solution

Jika $n=1$, maka jawabanya adalah $1$.

Jika $1 < n \le 3$, maka jawabanya adalah NO SOLUTION, atau tidak ada solusi, karena tidak peduli menggunakan cara apapun, tidak mungkin untuk membuat dua buah angka berjejeran memiliki selisih lebih dari satu.

Jika $n \ge 4$, maka akan selalu ada solusi.

Solusi bisa dikonstruksi dengan memulai dari angka $1$, tepat dii indeks ke-$2$ lalu kemudian naik satu persatu dengan melompatasi satu elemen, misal jika $n=7$, maka lakukan perulangan pertama untuk menyusun jawaban seperti berikut:

$$\_, 1, \_, 2, \_, 3, \_$$
Lalu, lakukan perulangan kedua yang dimulai dari indeks ke-$1$, lalu melanjutkan pengisian dari nilai sebelumnya (yaitu $3$, sehingga sekarang dimulai dari $4$) ke depan, sehingga sekarang susunan array menjadi seperti berikut:

$$4,1,5,2,6,3,7$$
Dan permutasi dengan selisih berpasangan selalu lebih dari satu berhasil dibuat.

## Proof of Correctness

> [!TIP]
> Kenapa solusi ini selalu berhasil?

Berdasarkan algoritma konstruksi yang kita rancang, seluruh angka dari $1$ hingga $n$ dibagi dan ditempatkan secara sistematis ke dalam dua fase pengisian indeks yang saling berselang-seling.

Pada fase pertama, angka-angka dari $1$ hingga $\lfloor n/2 \rfloor$ ditempatkan pada posisi-posisi indeks genap (melompat satu elemen), sehingga jarak antar angka yang berurutan secara nilai (seperti angka $1$ dan $2$, atau $2$ dan $3$) di dalam fase ini selalu terpisah oleh minimal satu slot kosong.

Pada fase kedua, sisa angka dari $\lceil n/2 \rceil$ hingga $n$ dimasukkan secara berurutan untuk mengisi slot-slot kosong yang tersisa dari depan, yang secara otomatis menyisipkan angka-angka bernilai lebih besar di antara angka-angka fase pertama.

Karena setiap perpindahan langkah pengisian melompati satu posisi dan langsung menempatkan nilai berikutnya pada slot yang terpisah, selisih mutlak antara elemen-elemen yang diletakkan berdampingan secara fisik di dalam array dijamin akan selalu lebih besar dari $1$ ($> 1$), sehingga permutasi valid berhasil terbentuk tanpa ada pelanggaran aturan.

> [!TIP]
> Kenapa tidak ada solusi untuk $1 < n \le 3$?

* Untuk $n = 2$, satu-satunya permutasi yang mungkin adalah $[1, 2]$ dan $[2, 1]$. Jika kita hitung selisih mutlak antara elemen yang bersebelahan, hasilnya adalah $\vert{}1 - 2\vert{} = 1$. Padahal, syarat soal mewajibkan selisih antar elemen bersebelahan harus lebih besar dari satu ($> 1$).
* Untuk $n = 3$, permutasi yang mungkin dari angka $1, 2, 3$ adalah:
	* $[1, 2, 3]$ $\rightarrow$ selisihnya $1$ dan $1$
	* $[1, 3, 2]$ $\rightarrow$ selisihnya $2$ dan $1$
	* $[2, 1, 3]$ $\rightarrow$ selisihnya $1$ and $2$
	* $[2, 3, 1]$ $\rightarrow$ selisihnya $1$ and $2$
	* $[3, 1, 2]$ $\rightarrow$ selisihnya $2$ and $1$
	* $[3, 2, 1]$ $\rightarrow$ selisihnya $1$ and $1$


* Pada setiap kemungkinan susunan untuk $n = 3$, selalu ada setidaknya satu pasang angka berurutan ($1$ dengan $2$, atau $2$ dengan $3$) yang letaknya berdampingan langsung, sehingga menghasilkan selisih mutlak sebesar $1$.
* Oleh karena itu, untuk rentang $1 < n \le 3$, secara matematika mustahil untuk menyusun angka-angka tersebut tanpa membuat setidaknya ada dua angka berjejer yang berselisih tepat $1$.
## Code Implementation

```cpp
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    int n;
    cin >> n;
    vector<int> vec(n);

    if (n <= 3) {
        if (n == 1) {
            cout << 1;
        } else {
            cout << "NO SOLUTION";
        }
        return 0;
    }

    int cur = 1;
    for (int i = 1; i < n; i += 2) {
        vec[i] = cur++;
    }

    for (int i = 0; i < n; i += 2) {
        vec[i] = cur++;
    }

    for (const auto& x : vec) {
        cout << x << " ";
    }

    return 0;
}
```
