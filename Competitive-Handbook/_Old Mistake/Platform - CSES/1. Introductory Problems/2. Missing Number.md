# Missing Number

![](2.%20Missing%20Number-1.png)

## Problem
Diberikan seluruh angka dari $1$, $2$, hingga $n$ kecuali satu angka. Tugasmu adalah mencari angka yang hilang tersebut.

## Solution
Terima semua angka pada array yang berukuran $n-1$. Setelah itu, sorting secara *ascending*, lalu kemudian lakukan perulangan dari $1$ hingga $n-1$. Selama perulangan, lakukan pengecekan apakah $a_i \equiv i$. Jika sekali saja kondisi ini tidak terpenuhi, maka artinya satu angka tersebut baru saja ditemukan, sehingga outputkan $i$.

Tapi jika semua perulangan dari $1$ hingga $n-1$ tidak mendapati kondisi $a_i \ne i$, maka artinya angka yang hilang tersebut adalah $n$ itu sendiri, sehingga outputkan $n$.
## Proof of Correctness

> [!TIP]
> Apa yang membuat solusi ini dijamin berhasil?

Setelah array diurutkan secara *ascending*, setiap elemen yang lengkap dan berurutan dari $1$ sampai $n-1$ seharusnya menempati posisi indeks yang bersesuaian persis dengan nilainya sendiri ($a_i = i$).

Ketika salah satu angka dari rentang $1$ sampai $n$ hilang, proses pengurutan akan merapatkan elemen-elemen yang tersisa, sehingga pada titik tertentu akan terjadi pergeseran posisi yang menyebabkan kondisi kesetaraan nilai dan indeks ($a_i = i$) pertama kalinya gagal atau tidak terpenuhi.

Ketidakpastian atau celah pertama yang ditemukan pada indeks $i$ tersebut menjamin secara matematis bahwa angka $i$ adalah nilai yang hilang di tengah rentang.

Jika seluruh perulangan dari $1$ hingga $n-1$ berhasil dilewati tanpa ada satu pun pelanggaran kondisi, itu berarti tidak ada angka di tengah yang hilang, sehingga secara deduktif angka yang tidak hadir pastilah nilai terakhir dari rentang tersebut, yaitu $n$.

## Code Implementation

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> vec(n - 1);
    for (auto& x : vec) {
        cin >> x;
    }

    sort(vec.begin(), vec.end());
    for (int i = 0; i < n - 1; i++) {
        if (vec[i] != i + 1) {
            cout << i + 1;
            return 0;
        }
    }

    cout << n;

    return 0;
}
```
