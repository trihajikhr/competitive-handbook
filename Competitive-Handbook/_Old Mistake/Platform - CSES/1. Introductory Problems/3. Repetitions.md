# Repetitions

![](3.%20Repetitions-1.png)

## Problem

Diberikan sebuah sekuens DNA: sebuah *string* yang terdiri dari karakter A, C, G, dan T. Tugasmu adalah mencari repetisi terpanjang di dalam sekuens tersebut. Ini adalah *substring* dengan panjang maksimum yang hanya berisi satu jenis karakter saja.

## Solution

Deklarasi variabel penampung jawaban misal $maks$, dan variabel counter misal $curr$. Inisialisasi $maks = 0$, dan $curr = 1$. Setelah itu, lakukan perulangan dari indeks $1$ string hingga $n-1$, dengan asumsi $n$ adalah panjang string. 

Didalam perulangan, setiap terdapat kondisi $s[i] \equiv s[i+1]$, maka artinya terdapat dua karakter yang sama bersebelahan, sehingga tambahkan satu pada nilai $curr$. Ketika yang terjadi sebaliknya, yaitu $s[i] \ne s[i+1]$, maka ambil nilai $curr$ saat ini, dengan melakukan operasi $maks = max(maks, curr)$, lalu reset nilai $curr=1$.

Setelah operasi selesai, ada potensi bahwa karakter adalah sama, sehingga nilai $maks$ belum sempat diperbarui. Oleh karena itu, outputkan jawabanya dengan tetap menyertakan fungsi $max(maks, curr)$.

## Proof of Correctness

> [!TIP]
> Kenapa solusi ini dijamin berhasil?

Setelah string diproses melalui perulangan dari indeks $1$ hingga $n-1$, variabel `curr` secara akurat mencatat panjang rentetan karakter berurutan yang sama saat ini, sementara variabel `maks` selalu merekam rekor terpanjang dari rentetan sebelumnya setiap kali transisi karakter berubah ($s[i] \neq s[i+1]$).

Ketika rentetan karakter yang sama berlanjut sampai akhir string, perulangan akan berhenti tanpa sempat memicu kondisi transisi, sehingga nilai rekor rentetan terakhir tersebut hanya tersimpan di dalam `curr` dan belum sempat dibandingkan dengan `maks`.

Melakukan evaluasi akhir `max(maks, curr)` pada saat pencetakan memastikan bahwa rentetan karakter yang berakhir tepat di ujung string tidak terlewat dan ikut diperhitungkan dalam penentuan jawaban terpanjang.

> [!TIP]
> Kenapa nilai $curr$ diinisialisasi dengan $1$, baik diawal maupun saat transisi?

Nilai `curr` diinisialisasi dengan $1$ karena setiap kali kita mendeteksi karakter baru atau memulai perulangan, karakter tersebut **sudah dihitung sebagai satu kemunculan tunggal yang sah** (panjang awal rentetan adalah $1$).

Jika `curr` diinisialisasi dengan $0$, maka rentetan karakter tunggal yang tidak memiliki pasangan atau karakter pertama dari setiap kelompok tidak akan terhitung dengan benar.

Saat terjadi transisi ($s[i] \neq s[i+1]$), karakter pada indeks $s[i+1]$ sudah mulai dihitung sebagai awal dari rentetan baru, sehingga `curr` wajib direset kembali ke $1$, bukan ke $0$, untuk merekam kehadiran karakter baru tersebut.
## Code Implementation

```cpp
#include <iostream>
#include <string>
using namespace std;

auto main() -> int {
    string s;
    cin >> s;

    int maks = 0, curr = 1;
    for (int i = 0; i < (int)s.length(); i++) {
        if (s[i] == s[i + 1]) {
            curr++;
        } else {
            maks = max(maks, curr);
            curr = 1;
        }
    }

    cout << max(maks, curr);

    return 0;
}
```
