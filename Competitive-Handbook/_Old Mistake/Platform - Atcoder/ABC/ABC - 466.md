# Compromise

## [A - Compromise](https://atcoder.jp/contests/abc466/tasks/abc466_a)
Mudah saja, cukup lakukan pemeriksaan, apakah salah satu data yang diterima ada yang bukan negatif, atau terdapat kondisi dimana $x \ge 0$. Jika terdapat kondisi seperti ini, maka jawabanya adalah `No`, tapi jika tidak ada satupun angka yang memenuhi kondisi tersebut, maka semua angka pasti negatif, sehingga outputkan `Yes`.

```cpp
#include <iostream>
using namespace std;

auto main() -> int {
    int n;
    cin >> n;
    bool nega = true;
    for (int i = 0, x; i < n; i++) {
        cin >> x;
        if (x >= 0) {
            nega = false;
        }
    }

    cout << (nega ? "Yes" : "No");
    return 0;
}
```

## [B - Representative Balls](https://atcoder.jp/contests/abc466/tasks/abc466_b)

Buat array penampung berukuran $M$, dan tetapkan semua nilainya dengan $-1$. Kemudian, terima pasangan nilai $C_i$ dan $S_i$, lalu perbarui ukuran maksimal dari setiap warna, dengan mencari nilai maksimal dari setiap inputan dengan menggunakan $C_i$ sebagai indexing. Jika menggunakan 0-based index, maka pastikan sesuaikan nilai $C_i$ menjadi $C_i -1$.

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

auto main() -> int {
    int n, m;
    cin >> n >> m;
    vector<int> arr (m, -1);
    for(int i=0; i<n; i++){
        int a, b;
        cin >> a >> b;
        arr[a-1] = max(arr[a-1], b);
    }

    for(const auto& x : arr) {
        cout << x << " ";
    }

    return 0;
}
```

## [C - Count Close Pairs](https://atcoder.jp/contests/abc466/tasks/abc466_c)

Problem interaktif, pastikan sudah belajar tentang problem interaktif sebelumnya!

Problem ini bisa diselesaikan dengan menggunakan algoritma atau pendekatan *sliding window*, memanfaatkan dua pointer $l$ dan $r$ . Dimana dilakukan perulangan pertama dengan menggunakan pointer $l$, dan kemudian pointer $r$ untuk perulangan kedua yang bergerak maju kedepan terus menerus hingga mendapati kondisi dimana judge memberikan `No`. Ketika `No` diberikan, maka artinya nilai dari $r-l$ sudah melebihi $1$, jadi ambil banyaknya pasangan $i,j$ yang selisihnya $\le 1$, dengan cara $r-l$. 

Namun karena nilai `No` diberikan ketika nilai dari $j$ sudah melebihi, maka kurangi lagi dengan $1$, supaya tepat. Sehingga, ketika output `No` diberikan, lakukan akumulasi $r-l-1$.

```cpp
#include <iostream>
using namespace std;

auto main() -> int {
    int n;
    cin >> n;

    int r = 2;
    long long ans = 0;

    for (int l = 1; l < n; l++) {
        if (l == r) {
            r++;
        }
        while (r <= n) {
            cout << "? " << l << " " << r << endl;
            string s;
            cin >> s;

            if (s == "Yes") {
                r++;
            } else {
                break;
            }
        }
        ans += (r - l - 1);
    }

    cout << "! " << ans << endl;
    return 0;
}
```

## [D - Placing Rooks](https://atcoder.jp/contests/abc466/tasks/abc466_d)

Perhatikan batasan dari banyaknya queri $M$, penggunaan array dua dimensi secara langsung akan menyebabkan Time Limit Exceed, karena adanya keharusan untuk melakukan traversal untuk melakukan pengecekan terhadap baris $x$ dan kolom $y$ untuk setiap queri.

Solusinya adalah dengan menggunakan cukup dua arrray berukuran $N$, untuk memetakan apakah terdapat bidak di baris $x$, dan apakah ada bidak di kolom $y$. Misal array tersebut adalah $row$ dan $col$. Setiap baris yang terisi oleh bidak, maka nilainya akan diisi dengan lokasi kolom dimana bidak itu berada. Dan untuk setiap kolom yang terisi bidak, nilai arraynya akan diisi dengan lokasi baris dimana bidak tersebut ada. Sehingga kondisi $row[x] = y$ dan $col[y] = x$ berlaku.

Tetapkan kedua array tersebut dengan $0$, karena ketika program pertama kali berjalan, belum ada bidak yang dimasukan. 

Untuk setiap queri, lakukan pengecekan, apakah baris tersebut sudah terisi atau belum. Jika sudah, array kolom yang menunjuk lokasi baris dimana bidak yang sebelumnya ada harus dihapus, sehingga data kolom harus dibersihkan dengan cara $col[row[x]]=0$. Lakukan pemeriksaan yang sama dengan kolom. Jika kolom terisi, maka hapus lokasi baris yang menunjuk baris dimana bidak sebelumnya berada, dengan $row[col[y]]=0$. 

Setelah itu, tetapkan nilai baru pada dua data tersebut, dengan $row[x]=y$ dan $col[y]=x$.

```cpp
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> row(n + 1, 0), col(n + 1, 0);
    for (int i = 0; i < m; i++) {
        int x, y;
        cin >> x >> y;

        if (row[x]) {
            col[row[x]] = 0;
        }

        if (col[y]) {
            row[col[y]] = 0;
        }

        row[x] = y;
        col[y] = x;
    }

    int cnt = 0;
    for (const auto& x : row) {
        cnt += x ? 1 : 0;
    }

    cout << cnt;

    return 0;
}
```

## [E - Range Flip](https://atcoder.jp/contests/abc466/tasks/abc466_e)

Kita akan menyebut kartu $l, l+1, \dots, r-1$ sebagai interval $[l, r)$.

Pertama, kita dapat mengasumsikan bahwa interval-interval yang dioperasikan bersifat saling lepas (_disjoint_). Hal ini dikarenakan jika kita mengambil solusi optimal yang memiliki panjang total interval operasi minimum, maka interval-interval tersebut akan saling lepas. Memang benar, jika dua interval yang tumpang tindih $[l_1, r_1)$ dan $[l_2, r_2)$ dioperasikan, kita dapat mengganti $[l_1, r_1), [l_2, r_2)$ dengan $[\min(l_1, l_2), \max(l_1, l_2))$ dan $[\min(r_1, r_2), \max(r_1, r_2))$ tanpa mengubah orientasi akhir kartu, namun memperkecil total panjang interval, yang kontradiktif dengan asumsi keminimalan. (Penggantian ini mungkin menghasilkan interval kosong, dalam hal ini kita bisa langsung melewatkan operasi tersebut.)

Oleh karena itu, masalah ini dapat disederhanakan menjadi masalah berikut:

Bagilah kartu $1, 2, \dots, N$ menjadi $(2K+1)$ potongan (_chunks_) (yang mungkin kosong). Untuk potongan dengan indeks ganjil, sisi depan menghadap ke atas; untuk potongan dengan indeks genap, sisi belakang yang menghadap ke atas. Temukan nilai total maksimum dari angka-angka yang tertulis pada sisi yang menghadap ke atas.

Sebagai alternatif, kita dapat mengasumsikan bahwa kita membaginya menjadi $(2K+1)$ potongan yang tidak kosong, namun hanya potongan pertama yang diperbolehkan untuk kosong.

Hal ini dapat dihitung dengan _dynamic programming_, di mana $dp_{i,j}$ adalah nilai total maksimum pada sisi yang menghadap ke atas di antara kartu $1, 2, \dots, i$, ketika kartu $i$ termasuk dalam potongan ke-$j$. Kompleksitas waktunya adalah $O(NK)$.

**Versiku:**

Ketahui Algoritma Kadane, dan semuanya akan menjadi lebih mudah! Jika belum tahu apa itu Algoritma Kadane, pelajari terlebih dahulu!

Jika biasanya Algoritma Kadane ditujukan untuk mendapatkan jumlah subarray maksimum dari sebuah array, kita bisa memodifikasinya sedikit pada kasus ini. 

Alur kerja penyelesaianya adalah, pertama-tama kita akumulasikan nilai $\sum A_i$ dari semua kartu, karena pada awalnya sisi $A$ yang sedang menghadap keatas. Lalu, selanjutnya kita hanya perlu menyimpan nilai $C_i = B_i - A_i$, yaitu profit potensial dari setiap kartu. Simplenya, jika nilai $C_i >0$, maka membalik kartu tersebut akan mendatangkan profit, dan jika $C_i \le 0$, maka membalik kartu tidak membawa keuntungan apa-apa.

Pada soal, kita diminta untuk memaksialkan profit dengan membalik subarray berukuran berapapun, sebanyak $K$ kali di tempat manapun. Ini artinya kita harus mencari subarray pada array yang saling terpisah sebanayk $K$, untuk memaksimalkan profit. Ini artinya, kita bisa menggunakan algoritma Kadane sebanyak $K$ kali, dan mencari subarray dengan akumulasi maksimal, untuk ditambahkan pada jawaban.

Sampai sini, tantanganya adalah:
- Apakah menjalankan Algoritma Kadane sebanyak $K$ kali aman dari batas waktu?
- Jika nilai maksimum dari subarray sudah diambil, bagaimana caranya memastikan rentang yang sama tidak diambil lagi?
- Bagaimana jika semua profit potensialnya negatif?

Tantangan pertama sebenarnya aman, batasan waktu adalah 2 detik, dan kompleksitas dari menjalankan Algoritma Kadane adalah $O(N)$, sehingga total kompleksitas menjadi $O(N \cdot K)$. Untuk nilai $N$ sendiri maksimalnya adalah $2 \times 10^5$, sehingga masih aman dalam batas waktu (komputer modern menjalankan sekitar $10^9$ operasi perdetik).

Tantangan kedua, disini kita perlu memodifikasi Algoritma Kadane, untuk mengambil juga indeks untuk rentang kiri dan kanan dari subarray maksimum yang diambil, sehingga di setiap $K$ perulangan, rentang tersebut bisa kita negasikan menjadi negatif, sehingga tidak akan diambil lagi.

Tantangan ketiga, setelah beberapa operasi $K$, mungkin semua profit potensial sudah diambil, sehingga semua nilai profit menjadi negatif karena kita negasikan. Pada kondisi ini, kita bisa menghentikan operasi algoritma Kadane, dengan mengecek apakah hasil dari operasi Kadane masih positif atau negatif. Jika nilanya sudah mencapai negatif, artinya tidak ada profit lagi yang masih bisa diambil, sehingga hentikan perulangan dengan segera.

```cpp
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<int> prof(n + 1, 0);
    long long sum = 0;
    for (int i = 1; i <= n; i++) {
        int a, b;
        cin >> a >> b;
        sum += a;
        prof[i] = b - a;
    }

    while (k--) {
        int start = 0, end = 0, temp_start = 0;
        long long current_max = -1e18, global_max = -1e18;

        for (int i = 1; i <= n; i++) {
            if (prof[i] > current_max + prof[i]) {
                current_max = prof[i];
                temp_start = i;
            } else {
                current_max += prof[i];
            }

            if (current_max > global_max) {
                global_max = current_max;
                start = temp_start;
                end = i;
            }
        }

        if (global_max <= 0) {
            break;
        }

        sum += global_max;
        for (int i = start; i <= end; i++) {
            prof[i] *= -1;
        }
    }

    cout << sum;

    return 0;
}
```

## F
Mari kita pertimbangkan apa yang terjadi ketika $0, 1, \dots, X-1$ diganti dengan sisa pembagiannya saat dibagi dengan $M$.

Untuk setiap bagian (chunk) sepanjang $M$, sisa pembagian $0, 1, \dots, M-1$ masing-masing muncul satu kali. Oleh karena itu, bagian $0, 1, \dots, M-1$ muncul sebanyak $\lfloor \frac{X}{M} \rfloor$ kali, dengan sisa bagian $0, 1, \dots, (X \pmod M)-1$ muncul satu kali pada akhirnya.

Dengan demikian, dengan menjaga himpunan nilai saat ini sebagai multiset dalam bentuk "$k$ salinan dari $[0, x)$", setiap interval dapat dipecah menjadi jumlah dari paling banyak dua interval.

Simulasi ini berjalan cukup cepat dengan menyimpan interval-interval tersebut dalam _priority queue_ dan menggabungkan interval-interval dengan nilai akhir $x$ yang sama.

**Analisis kompleksitas:**

Penerapan operasi $\pmod M$ memecah $[0, x)$ menjadi $[0, M)$ dan $[0, x \pmod M)$. Interval $[0, M)$ dibagikan (shared) ke seluruh interval. Selain itu, nilai $x \pmod M$ adalah $x$ atau kurang dari $\frac{x}{2}$, sehingga ketika $[0, M)$ dikeluarkan, $O(\log x)$ interval dihasilkan dari satu interval.

Karena setiap aksi menghasilkan $[0, M)$, kita dapat mengevaluasi jumlah interval dalam _priority queue_ sebagai $O(N)$. Maka, kompleksitas waktu keseluruhan adalah $O(N \log N \log X)$.

Permasalahan ini dapat diselesaikan dengan mengimplementasikan algoritma ini secara tepat.
