# String Hash Validation

## Task

Kamu diberikan sebuah _string_ $S$ yang hanya terdiri dari huruf kecil alfabet Inggris (`a-z`). Tugas kamu adalah menghitung nilai _polynomial rolling hash_ dari _string_ tersebut menggunakan parameter standar berikut:

- Konstanta basis: $p = 31$
- Konstanta modulus: $m = 10^9 + 9$
- Konversi karakter: `a` $\rightarrow 1$, `b` $\rightarrow 2$, $\dots$, `z` $\rightarrow 26$
### Input

Input terdiri dari satu baris yang berisi sebuah _string_ $S$.

### Output

Cetak sebuah nilai integer yang menunjukkan hasil kalkulasi _hash_ dari _string_ $S$ sesuai dengan rumus _polynomial rolling hash_.

### Constraints

- $1 \le \vert{}S\vert{} \le 10^5$, di mana $\vert{}S\vert{}$ menyatakan panjang dari _string_ $S$.
- _String_ $S$ hanya berisi karakter `a` sampai `z`.

### Example Input 1


```
alley
```

### Example Output 1

```
23248885
```

### Example Input 2

```
a
```

### Example Output 2

```
1
```

## Jawaban

```cpp
#include <iostream>
#include <string>
using namespace std;

auto compute_hash(const string& s) -> long long {
    const int p = 31;
    const int m = 1e9 + 9;
    long long hash_value = 0;
    long long p_pow = 1;
    for (char c : s) {
        hash_value = (hash_value + (c - 'a' + 1) * p_pow) % m;
        p_pow = (p_pow * p) % m;
    }

    return hash_value;
}

auto main() -> int {
    string s;
    cin >> s;

    cout << compute_hash(s);
    return 0;
}

```
