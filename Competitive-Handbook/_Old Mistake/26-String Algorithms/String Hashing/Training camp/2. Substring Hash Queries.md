# Substring Hash Queries

## Task

Kamu diberikan sebuah _string_ $S$ sepanjang $N$ yang hanya terdiri dari huruf kecil alfabet Inggris. Kamu juga akan diberikan $Q$ buah _queries_. Setiap _query_ terdiri dari dua buah indeks $i$ dan $j$ (menggunakan format _1-indexed_). Untuk setiap _query_, tugas kamu adalah mencetak nilai _hash_ dari _substring_ $S[i \dots j]$ secara instan menggunakan rumus kalkulasi _substring hash_ yang efisien ($\mathcal{O}(1)$ per _query_ setelah melakukan _preprocessing_ $\mathcal{O}(N)$).

Gunakan parameter yang sama dengan soal sebelumnya:

- $p = 31$
    
- $m = 10^9 + 9$
    
- `a` $\rightarrow 1$, `b` $\rightarrow 2$, $\dots$, `z` $\rightarrow 26$
    

### Input

Baris pertama berisi dua buah integer $N$ dan $Q$, yang menyatakan panjang _string_ dan banyaknya _queries_.

Baris kedua berisi sebuah _string_ $S$ sepanjang $N$.

$Q$ baris berikutnya masing-masing berisi dua buah integer $i$ dan $j$ ($1 \le i \le j \le N$), yang menyatakan batas awal dan batas akhir dari _substring_ yang ditanyakan.

### Output

Untuk setiap _query_, cetak nilai _hash_ dari _substring_ tersebut pada baris baru.

### Constraints

- $1 \le N, Q \le 10^5$
- $1 \le i \le j \le N$
- _String_ $S$ hanya berisi karakter `a` sampai `z`.

### Example Input

```
5 3
alley
1 5
1 1
2 4
```

### Example Output

```
2469685
1
160859
```

_Petunjuk Tambahan:_ Ingat untuk berhati-hati saat melakukan operasi pengurangan pada modulo agar tidak menghasilkan nilai negatif (gunakan trik `(hasil % m + m) % m`). Kamu bisa menggunakan metode pembagian dengan _modular multiplicative inverse_ atau metode perkalian pangkat seperti yang ada di materi pembanding.

## Jawaban

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

const long long m = 1e9 + 9;
const long long p = 31;

auto compute_hash(const string& s, vector<long long>& hash, vector<long long>& p_pow) -> void {
    long long hash_value = 0;
    int idx = 0;
    for (char c : s) {
        hash_value = (hash_value + (c - 'a' + 1) * p_pow[idx]) % m;
        hash[idx++] = hash_value;
    }
}

auto main() -> int {
    // Optimasi I/O untuk kompetisi pemrograman
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n, q;
    cin >> n >> q;

    string s;
    cin >> s;

    // Precompute pangkat dari p
    vector<long long> p_pow(n);
    p_pow[0] = 1;
    for (int i = 1; i < n; i++) {
        p_pow[i] = (p_pow[i - 1] * p) % m;
    }

    vector<long long> hash(n, 0);
    compute_hash(s, hash, p_pow);
    hash.insert(hash.begin(), 0);

    while (q--) {
        int l, r;
        cin >> l >> r;
        
        // Mengatasi nilai negatif akibat pengurangan modulo
        long long cur_h = (hash[r] - hash[l - 1] + m) % m;
        
        // Menyamakan posisi pangkat (alignment) dengan mengalikan p^(n - l)
        cur_h = (cur_h * p_pow[n - l]) % m;
        
        cout << cur_h << "\n";
    }

    return 0;
}
```
