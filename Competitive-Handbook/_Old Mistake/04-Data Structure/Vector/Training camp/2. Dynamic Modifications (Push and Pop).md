# Dynamic Modifications (Push and Pop)

## Task

Kamu mulai dengan sebuah `vector` yang kosong. Diberikan $Q$ buah _query_. Setiap _query_ bisa berupa salah satu dari dua jenis berikut:

- `1 x`: Masukkan integer $x$ ke bagian paling belakang (_end_) dari `vector`.
    
- `2`: Hapus _element_ terakhir dari `vector`. Jika `vector` sudah kosong, abaikan _query_ ini.
    

Setelah memproses seluruh _query_, cetak ukuran dari `vector` saat ini, kemudian cetak seluruh isi _element_-nya.

### Input

Baris pertama berisi sebuah integer $Q$, yaitu jumlah _query_.

$Q$ baris berikutnya masing-masing berisi sebuah _query_ sesuai format di atas.

### Output

Baris pertama cetak sebuah integer yang menunjukkan ukuran akhir dari `vector`.

Baris kedua cetak seluruh _element_ yang tersisa di dalam `vector` secara berurutan, dipisahkan oleh spasi. Jika `vector` kosong, baris kedua dibiarkan kosong atau cetak baris baru saja.

### Constraints

- $1 \le Q \le 10^5$
    
- Untuk _query_ jenis 1, $-10^9 \le x \le 10^9$.
    

### Example Input


```
6
1 5
1 10
2
1 3
1 7
2
```

### Example Output


```
2
5 3
```

## Jawaban

```cpp
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    vector<int> vec;
    int q;
    cin >> q;

    while (q--) {
        int t;
        cin >> t;
        if (t == 1) {
            int x;
            cin >> x;
            vec.push_back(x);
        } else if (t == 2) {
            if (!vec.empty()) {
                vec.pop_back();
            }
        }
    }

    cout << vec.size() << "\n";
    for (const auto& x : vec) {
        cout << x << " ";
    }
    return 0;
}
```
