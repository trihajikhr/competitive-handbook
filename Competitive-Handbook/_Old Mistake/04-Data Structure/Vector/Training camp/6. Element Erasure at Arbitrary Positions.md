# lement Erasure at Arbitrary Positions

## Task

Kamu diberikan sebuah `vector` yang awalnya berisi $N$ buah integer. Kamu akan menerima $Q$ buah _query_. Setiap _query_ meminta kamu untuk menghapus elemen yang berada tepat pada indeks ke-$i$. Elemen-elemen yang berada di sebelah kanan indeks tersebut akan bergeser ke kiri secara otomatis untuk mengisi celah yang kosong.

Setelah memproses semua _query_, cetak ukuran akhir dari `vector` beserta seluruh elemen yang tersisa.

### Input

Baris pertama berisi dua buah integer $N$ dan $Q$.

Baris kedua berisi $N$ buah integer awal yang dipisahkan oleh spasi.

$Q$ baris berikutnya masing-masing berisi sebuah integer $i$, yang menyatakan posisi indeks elemen yang ingin dihapus.

### Output

Baris pertama cetak sebuah integer yang menunjukkan ukuran akhir dari `vector`.

Baris kedua cetak seluruh elemen yang tersisa di dalam `vector` setelah semua operasi selesai, dipisahkan oleh spasi. Jika `vector` menjadi kosong, cukup cetak baris baru.

### Constraints

- $1 \le N \le 10^3$
    
- $1 \le Q \le 10^3$
    
- Nilai setiap elemen berada dalam rentang $[-10^9, 10^9]$.
    
- Setiap query dijamin memiliki indeks $i$ yang valid terhadap ukuran `vector` saat query tersebut diproses ($0 \le i < \text{ukuran vector saat itu}$).
    

### Example Input


```
5 3
10 20 30 40 50
2
0
2
```

### Example Output


```
2
20 40
```

**Penjelasan Eksperimen:**

1. Awal: `[10, 20, 30, 40, 50]`
    
2. `2` $\rightarrow$ Hapus elemen di indeks 2 (`30`): `[10, 20, 40, 50]`
    
3. `0` $\rightarrow$ Hapus elemen di indeks 0 (`10`): `[20, 40, 50]`
    
4. `2` $\rightarrow$ Hapus elemen di indeks 2 (`50`): `[20, 40]`

## Jawaban

```cpp
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    int n, q;
    cin >> n >> q;
    vector<int> vec(n);
    for (auto& x : vec) {
        cin >> x;
    }

    while (q--) {
        int t;
        cin >> t;
        vec.erase(vec.begin() + t);
    }

    cout << vec.size() << "\n";
    for (const auto& x : vec) {
        cout << x << " ";
    }

    return 0;
}
```
