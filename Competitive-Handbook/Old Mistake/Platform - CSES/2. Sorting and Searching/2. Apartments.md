# Apartments

## Problem
Terdapat $n$ pelamar dan $m$ apartemen kosong. Tugasmu adalah membagikan apartemen tersebut sehingga sebanyak mungkin pelamar mendapatkan apartemen.

Setiap pelamar memiliki ukuran apartemen yang diinginkan, dan mereka akan menerima apartemen apa pun yang ukurannya cukup dekat dengan ukuran yang mereka inginkan, atau ukuran apartemenya memiliki selisih tidak lebih dari $k$ dari ukuran yang mereka inginkan.
## Solution

Kita bisa menggunakan teknik *two pointer*, yaitu menggunakan dua variabel indexing. Itu adalah ide utamanya. Tapi mari kita mulai penjelasanya dari awal.

Pertama, ketahui bahwa nilai dari elemen-elemenya paling besar adalah hingga $10^9$, ini jelas berada di ujung batas kapasitas `int` biasa, jadi kita gunakan tipe data `long long` untuk mengantisipasi terjadinya *integer overflow*. Setelah itu terima $n$ ukuran apartemen setiap orang yang diinginkan, dan juga terima $m$ ukuran apartement yang benar-benar tersedia.

Setelah itu, agar proses pelacakan bisa berjalan beriringan sehingga kompleksitas waktu pencarian menjadi hanya $O(n)$, urutkan kedua data tersebut secara *ascending*. Setelah terurut, teknik *two pointer* kita jalankan disini.

Tetapkan nilai $l=0$, dan $r=0$. Variabel $l$ akan menjadi indexing untuk untuk array ukuran apartemen yang diminta, sedangkan variabel $r$ akan menjadi indexing untuk array ukuran apartemen yang tersedia. 

Didalam perulangan `while`, sebenarnya kita hanya perlu melakukan pemeriksaan sederhana dengan melibatkan $k$ sebagai batas toleransi selisih yang diperbolehkan. Jika semisal array ukuran array yang diinginkan adalah $req$ dan array untuk ukuran array yang tersedia adalah $apart$, maka berlaku dimana jika $req[l] + k < apart[r]$, maka artinya ukuran $req[l]$ terlalu kecil, sehingga naikan nilai $l$. Dan jika $req[l] - k > apart[r]$, maka artinya ukuran $req[l]$ terlalu besar, sehingga kita naikan nilai $r$. Tapi jika kedua kondisi tersebut tidak terpenuhi, artinya nilai $req[l]$ dan $apart[r]$ memiliki selisih dibawah $k$, atau $|req[l] - apart[r]| \le k$. Ketika ini terjadi, artinya kita menemukan pasangan yang tepat, sehingga kita mendapatkan satu jawaban tambahan, dan naikan kedua nilai $l$ dan $r$.

Berikut implementasinya:

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

using ll = long long;
auto main() -> int {
    ll n, m, k;
    cin >> n >> m >> k;
    vector<ll> req(n), apart(m);
    for (int i = 0; i < n; i++) {
        cin >> req[i];
    }

    for (int i = 0; i < m; i++) {
        cin >> apart[i];
    }

    sort(req.begin(), req.end());
    sort(apart.begin(), apart.end());

    int ans = 0, l = 0, r = 0;
    while (l < n && r < m) {
        if (req[l] + k < apart[r]) {
            l++;
        } else if (req[l] - k > apart[r]) {
            r++;
        } else {
            ans++, l++, r++;
        }
    }

    cout << ans;
    return 0;
}
```
