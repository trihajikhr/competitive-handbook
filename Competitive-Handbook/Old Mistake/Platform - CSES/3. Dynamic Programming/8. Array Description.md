# Array Description

![](8.%20Array%20Description-1.png)

## Problem

Anda mengetahui bahwa sebuah *array* memiliki $n$ bilangan bulat antara $1$ dan $m$, dan selisih absolut antara dua nilai yang berdekatan paling banyak $1$.

Diberikan deskripsi dari *array* tersebut di mana beberapa nilainya mungkin tidak diketahui, tugas Anda adalah menghitung banyaknya *array* yang memenuhi deskripsi tersebut.

## Solution
Persoalan **Array Description** di CSES membawa variasi DP pada barisan (*sequence*) dengan batasan selisih antar elemen bersebelahan (*neighbor constraint*).

### 1. Memahami Inti Masalah

Diberikan sebuah array bernilai $n$ elemen $x = [x_1, x_2, \dots, x_n]$ dan sebuah batas atas nilai $m$.

Array ini memiliki aturan ketat:

1. Setiap elemen $x_i$ harus bernilai antara $1$ hingga $m$ ($1 \le x_i \le m$).
2. Selisih absolut antara dua elemen yang bersebelahan maksimal $1$, yaitu $\vert{}x_i - x_{i-1}\vert{} \le 1$. Artinya, jika sebuah $x_{i-1} = v$, maka $x_i$ hanya boleh bernilai $v-1$, $v$, atau $v+1$.

Beberapa elemen pada array bernilai $0$, yang berarti nilai tersebut **hilang/bebas diisi**. Jika $x_i \neq 0$, maka nilainya sudah terkunci dan tidak boleh diubah.

Tujuannya adalah menghitung banyaknya cara berbeda untuk mengisi semua nilai $0$ sehingga seluruh array memenuhi aturan di atas. Cetak hasilnya dalam modulo $10^9 + 7$.

### 2. Formulasi State DP

Karena nilai $x_i$ sangat bergantung pada nilai elemen sebelumnya $x_{i-1}$, kita perlu mencatat indeks posisi saat ini sekaligus nilai yang ditaruh pada posisi tersebut.

* **Definisi State:** $dp[i][v]$ = banyaknya cara yang valid untuk mengisi prefix array dari indeks $1$ sampai $i$, dengan syarat elemen ke-$i$ bernilai $v$ (di mana $1 \le v \le m$).
* **Target:** Jumlah seluruh kemungkinan nilai pada elemen terakhir $n$:

$$\text{Hasil} = \sum_{v=1}^{m} dp[n][v] \pmod{10^9 + 7}$$



### 3. Base Case & Inisialisasi

Tinjau elemen pertama ($i = 1$):

* Jika $x_1 = 0$ (bebas): Elemen pertama bisa diisi angka berapa saja dari $1$ sampai $m$.

$$dp[1][v] = 1 \quad \text{untuk semua } 1 \le v \le m$$


* Jika $x_1 = k$ di mana $k \neq 0$ (terkunci): Elemen pertama hanya bisa bernilai $k$.

$$dp[1][k] = 1, \quad \text{dan } dp[1][v] = 0 \text{ untuk } v \neq k$$


### 4. Transisi DP (Relasi Rekurens)

Untuk mengisi elemen ke-$i$ dengan nilai $v$, nilai elemen sebelumnya $x_{i-1}$ haruslah bernilai $v-1$, $v$, atau $v+1$ (selama nilainya berada dalam rentang $[1, m]$).

Berdasarkan aturan penjumlahan:

$$dp[i][v] = dp[i-1][v-1] + dp[i-1][v] + dp[i-1][v+1]$$

Namun, kita harus memperhatikan kondisi penguncian elemen $x_i$:

1. **Jika $x_i \neq 0$ dan $v \neq x_i$:** $dp[i][v] = 0$ (karena posisi ini dipaksa harus bernilai $x_i$).
2. **Jika $x_i = 0$ ATAU $v == x_i$:** Hitung penjumlahan dari $dp[i-1][v-1] + dp[i-1][v] + dp[i-1][v+1]$.

### 5. Strategi Penyelesaian (Bottom-Up)

1. **Inisialisasi Matrix:** Buat matriks $dp[n+1][m+2]$ dengan nilai $0$.
2. **Set Base Case:** Isi baris $i = 1$ sesuai nilai $x_1$.
3. **Iterasi Posisi ($i$):** Perulangan luar berjalan dari $i = 2$ sampai $n$.
4. **Iterasi Nilai Candidate ($v$):** Perulangan dalam berjalan dari $v = 1$ sampai $m$.
	* Jika $x_i \neq 0$ dan $v \neq x_i$, lewati ($dp[i][v] = 0$).
	* Jika valid, set $dp[i][v] = (dp[i-1][v-1] + dp[i-1][v] + dp[i-1][v+1]) \pmod{10^9 + 7}$.

5. **Output:** Jumlahkan seluruh $dp[n][v]$ untuk $1 \le v \le m$ lalu modulo $10^9 + 7$.
### Optimasi Ruang (Space Optimization)

Sama seperti persoalan DP barisan lainnya, baris $dp[i]$ hanya membutuhkan nilai dari baris sebelumnya $dp[i-1]$. Penggunaan memori bisa dioptimalkan dari $O(n \cdot m)$ menjadi $O(m)$ dengan hanya menyimpan array 1D untuk posisi sebelumnya dan posisi saat ini.

## Proof of Correctness
### PoC 1

> [!TIP]
> Kenapa pendekatan ini bisa mengatasi semua batasan dan menjadi formula yang benar?

Berikut adalah Proof of Correctness (PoC) mengenai validitas dan ketepatan formulasi Dynamic Programming pada masalah **Array Description**.

#### 1. Struktur Markovian dan Ketergantungan Lokal

Persoalan ini menetapkan aturan batasan selisih bersebelahan: untuk setiap $i \in \{2, \dots, n\}$, nilai $x_i$ hanya dibatasi oleh nilai $x_{i-1}$, yaitu $\vert{}x_i - x_{i-1}\vert{} \le 1$. Nilai $x_i$ sama sekali tidak dipengaruhi oleh elemen-elemen di posisi $i-2, i-3$, dan seterusnya secara langsung.

Sifat ini memenuhi **Properti Markov**: masa depan ($x_i$) bersifat independen dari masa lalu ($x_1, \dots, x_{i-2}$) jika diberikan nilai masa kini ($x_{i-1}$).

Oleh karena itu, seluruh informasi yang diperlukan untuk memastikan keabsahan susunan dari indeks $1$ sampai $i$ tersimpan secara sempurna di dalam pasangan $(i, v)$, di mana $i$ adalah posisi saat ini dan $v$ adalah nilai yang ditempatkan pada $x_i$.

#### 2. Sifat Saling Lepas (Disjoint) dan Partisi Ruang Keadaan

Misalkan $S(i, v)$ adalah himpunan semua barisan valid berpanjang $i$ yang diakhiri oleh nilai $v$ pada posisi ke-$i$.

Agar sebuah barisan berpanjang $i-1$ dengan nilai akhir $u$ dapat diperpanjang secara sah menjadi barisan berpanjang $i$ dengan nilai akhir $v$, syarat yang harus dipenuhi adalah $\vert{}v - u\vert{} \le 1$. Nilai $u$ yang memenuhi batasan ini hanya ada tiga kemungkinan, yaitu $u \in \{v-1, v, v+1\}$.

Himpunan-himpunan barisan yang diakhiri oleh nilai $u$ berbeda bersifat **saling lepas** (*mutually disjoint*):


$$S(i-1, v-1) \cap S(i-1, v) = \emptyset$$

Berdasarkan **Aturan Penjumlahan (*Sum Rule*)** dalam kombinatorika, total cara membentuk barisan valid berpanjang $i$ dengan elemen akhir $v$ adalah jumlah dari banyaknya cara membentuk barisan valid berpanjang $i-1$ yang diakhiri oleh $v-1$, $v$, dan $v+1$:

$$\vert{}S(i, v)\vert{} = \vert{}S(i-1, v-1)\vert{} + \vert{}S(i-1, v)\vert{} + \vert{}S(i-1, v+1)\vert{}$$

Persamaan ini persis mewakili relasi rekurens DP:


$$dp[i][v] = dp[i-1][v-1] + dp[i-1][v] + dp[i-1][v+1]$$

#### 3. Penanganan Elemen Terkunci dan Elemen Bebas secara Presisi

Formulasi ini secara otomatis menangani dua jenis kondisi elemen $x_i$:

1. **Elemen Terkunci ($x_i = k \neq 0$):**
   Ruang pilihan untuk $x_i$ dipangkas secara mutlak menjadi tepat 1 nilai. Untuk semua $v \neq k$, diset $dp[i][v] = 0$. Ini secara efektif mematikan seluruh cabang kombinasi yang tidak menghasilkan nilai $k$ pada indeks $i$, sehingga nilai-nilai yang tidak valid tersebut tidak diakumulasikan ke posisi $i+1$.
2. **Elemen Bebas ($x_i = 0$):**
   Tidak ada pemangkasan yang dilakukan. Semua $v \in [1, m]$ mengevaluasi nilai transisinya dari $i-1$, mewakili semua kemungkinan nilai yang bisa diisikan pada posisi tersebut.


#### 4. Pembuktian Induksi Matematika

* **Base Case ($i = 1$):**
	* Jika $x_1 = 0$, $dp[1][v] = 1$ untuk semua $v \in [1, m]$. Ada tepat 1 cara untuk membuat barisan panjang 1 dengan nilai akhir $v$.
	* Jika $x_1 = k$, $dp[1][k] = 1$ dan $dp[1][v] = 0$ untuk $v \neq k$. Tepat 1 cara yang bernilai $k$.
	  Kasus dasar terbukti benar.

* **Hipotesis Induksi:**
  Asumsikan untuk posisi $i-1$, nilai $dp[i-1][u]$ secara akurat menyimpan banyaknya barisan valid berpanjang $i-1$ yang diakhiri dengan angka $u$, untuk setiap $u \in [1, m]$.
* **Langkah Induksi:**
  Untuk posisi $i$, setiap calon nilai $v \in [1, m]$ hanya dapat dicapai dari $u \in \{v-1, v, v+1\} \cap [1, m]$. Berdasarkan hipotesis induksi, nilai $dp[i-1][u]$ untuk ketiga kandidat tersebut sudah valid dan optimal. Karena ketiga himpunan cabang ini saling lepas, penjumlahannya menghasilkan jumlah barisan valid berpanjang $i$ dengan nilai akhir $v$ secara tepat tanpa ada yang terlewat atau terhitung dua kali.

Dengan menjumlahkan seluruh $dp[n][v]$ untuk $1 \le v \le m$ di akhir iterasi, diperoleh total seluruh konfigurasi array $x$ yang memenuhi semua batasan masalah.

## Code Implementation

Menggunakan cara satu baris:

```cpp
#include <iostream>
#include <vector>
using namespace std;

void print(const vector<vector<int>>& dp) {
    for (const auto& row : dp) {
        for (const auto& x : row) {
            cerr << x << " ";
        }
        cerr << "\n";
    }
}

constexpr int M = 1e9 + 7;
auto main() -> int {
    int n, m;
    cin >> n >> m;
    vector<long long> arr(n + 1);

    for (int i = 1; i <= n; i++) {
        cin >> arr[i];
    }

    vector<vector<long long>> dp(n + 1, vector<long long>(m + 2, 0));

    if (arr[1] == 0) {
        for (int i = 1; i <= m; i++) {
            dp[1][i] = 1;
        }
    } else {
        dp[1][arr[1]] = 1;
    }

    for (int i = 2; i <= n; i++) {
        if (arr[i] != 0) {
            dp[i][arr[i]] = (dp[i - 1][arr[i] - 1] + dp[i - 1][arr[i]] + dp[i - 1][arr[i] + 1]) % M;
        } else {
            for (int j = 1; j <= m; j++) {
                dp[i][j] = (dp[i - 1][j - 1] + dp[i - 1][j] + dp[i - 1][j + 1]) % M;
            }
        }
    }

    long long ans = 0;
    for (int i = 0; i <= m; i++) {
        ans = (ans + dp[n][i]) % M;
    }

    cout << ans;

    return 0;
}
```

Menggunakan bantuan array `help` untuk mendapatkan 3 sisi array diatasnya:

```cpp
#include <iostream>
#include <vector>
using namespace std;

using VVLL = vector<vector<long long>>;
constexpr long long M = 1e9 + 7;

auto main() -> int {
    int n, m;
    cin >> n >> m;
    vector<int> arr(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        cin >> arr[i];
    }

    VVLL dp(n + 1, vector<long long>(m + 2, 0));

    if (arr[1] == 0) {
        for (int i = 1; i <= m; i++) {
            dp[1][i] = 1;
        }
    } else {
        dp[1][arr[1]] = 1;
    }

    vector<int> help = {-1, 0, 1};
    for (int i = 2; i <= n; i++) {
        if (arr[i] != 0) {
            for (int j = 0; j < 3; j++) {
                dp[i][arr[i]] = (dp[i][arr[i]] + dp[i - 1][arr[i] + help[j]]) % M;
            }
        } else {
            for (int j = 1; j <= m; j++) {
                for (int k = 0; k < 3; k++) {
                    dp[i][j] = (dp[i][j] + dp[i - 1][j + help[k]]) % M;
                }
            }
        }
    }

    long long sum_ans = 0;
    for (int i = 1; i <= m; i++) {
        sum_ans = (sum_ans + dp[n][i]) % M;
    }

    cout << sum_ans;
    return 0;
}
```
