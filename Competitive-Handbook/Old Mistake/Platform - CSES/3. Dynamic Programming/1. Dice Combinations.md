# Dice Combinations

![](1.%20Dice%20Combinations-1.png)

## Problem
Tugas Anda adalah menghitung banyaknya cara untuk membuat jumlah $n$ dengan melempar sebuah dadu satu kali atau lebih. Setiap lemparan menghasilkan nilai antara $1$ dan $6$.

Sebagai contoh, jika $n = 3$, terdapat $4$ cara:

* $1 + 1 + 1$
* $1 + 2$
* $2 + 1$
* $3$
## Solution

### 1. Memahami Inti Masalah

Kita diminta mencari **banyaknya cara** untuk mendapatkan jumlah total $n$ dengan melempar dadu bersisi $6$ (angka $1$ sampai $6$) beberapa kali.

Setiap lemparan dadu dapat menghasilkan nilai $d \in \{1, 2, 3, 4, 5, 6\}$. Karena urutan lemparan diperhitungkan (misal: lemparan $1 + 2$ dianggap berbeda dengan $2 + 1$), ini adalah masalah permutasi kombinasi penjumlahan.

### 2. Formulasi State DP

Langkah awal DP adalah mendefinisikan apa yang diwakili oleh nilai `dp[i]`.

* **Definisi State:** $dp[x]$ = banyaknya cara untuk membentuk jumlah nilai sebesar $x$.
* **Target:** Kita ingin mencari nilai dari $dp[n]$.


### 3. Base Case (Kondisi Dasar)

Kapan kita tahu sebuah kombinasi lemparan berhasil terbentuk?

* $dp[0] = 1$: Ada tepat $1$ cara untuk membuat jumlah $0$, yaitu dengan **tidak melempar dadu sama sekali**. Ini adalah pondasi awal untuk membangun nilai-nilai berikutnya.

### 4. Transisi DP (Relasi Rekurens)

Untuk mencari cara membentuk jumlah $x$, bayangkan nilai lemparan dadu **terakhir** yang kita dapatkan. Lemparan terakhir tersebut pasti salah satu dari angka 1, 2, 3, 4, 5, atau 6.

* Jika lemparan terakhir bernilai $1$, maka sisa jumlah yang harus dibentuk sebelumnya adalah $x - 1$. Banyak caranya adalah $dp[x - 1]$.
* Jika lemparan terakhir bernilai $2$, sisa jumlah sebelumnya adalah $x - 2$. Banyak caranya adalah $dp[x - 2]$.
* ...dan seterusnya hingga angka $6$.

Karena semua kemungkinan lemparan terakhir ini bersifat independen, kita tinggal **menjumlahkan** semua kemungkinan dari sisa jumlah tersebut:

$$dp[x] = dp[x-1] + dp[x-2] + dp[x-3] + dp[x-4] + dp[x-5] + dp[x-6]$$

**Catatan Penting saat Iterasi:**
Untuk nilai $x - d$, pastikan $x - d \ge 0$. Jika $x - d < 0$, artinya angka dadu $d$ terlalu besar untuk mencapai jumlah $x$, sehingga tidak bisa diperhitungkan.


### 5. Strategi Penyelesaian (Bottom-Up)

1. **Inisialisasi Array:** Buat array $dp$ berukuran $n + 1$, lalu isi seluruh nilainya dengan `0`. Set $dp[0] = 1$.
2. **Iterasi:** Jalankan perulangan outer dari $i = 1$ sampai $n$ (menghitung nilai dari jumlah terkecil ke terbesar).
3. **Pilihan Lemparan:** Di dalam perulangan outer, buat perulangan inner untuk tiap mata dadu $d \in [1, 6]$.
4. **Update State:** Jika $i - d \ge 0$, tambahkan nilai $dp[i - d]$ ke $dp[i]$.
5. **Aritmatika Modulo:** Karena hasilnya bisa sangat besar dan melebihi jangkauan tipe data standar, lakukan operasi modulo $10^9 + 7$ di setiap penjumlahan.

### Mengapa Pendekatan Ini Bekerja?

Pendekatan *bottom-up* ini menjamin bahwa ketika kamu sedang menghitung $dp[x]$, semua nilai $dp[x-1]$ hingga $dp[x-6]$ sudah selesai dihitung sebelumnya. Dengan begitu, kamu membangun jawaban untuk nilai $n$ secara bertahap dari kasus-kasus yang lebih kecil tanpa melakukan perhitungan ulang (*overlapping subproblems*).

Secara kompleksitas waktu, algoritma ini berjalan dalam $O(n)$ karena kamu cukup melakukan 6 kali operasi penjumlahan untuk setiap nilai dari $1$ hingga $n$.

### Penjelasan mengalir


Persoalan *Dice Combinations* di CSES adalah masalah *Dynamic Programming* fundamental yang melatih cara berpikir rekursif dan state transition. Pada dasarnya, kita diminta mencari banyaknya cara untuk mendapatkan jumlah total $n$ dengan melempar dadu bersisi 6, yaitu angka 1 sampai 6, beberapa kali. Setiap lemparan dadu dapat menghasilkan nilai $d \in \{1, 2, 3, 4, 5, 6\}$. Karena urutan lemparan diperhitungkan, seperti lemparan $1 + 2$ yang dianggap berbeda dengan $2 + 1$, persoalan ini menjadi masalah permutasi kombinasi penjumlahan.

Untuk memulainya, langkah awal *Dynamic Programming* adalah mendefinisikan apa yang diwakili oleh nilai $dp[i]$. Di sini, $dp[x]$ didefinisikan sebagai banyaknya cara untuk membentuk jumlah nilai sebesar $x$, dengan target akhir mencari nilai dari $dp[n]$. Fondasi dari perhitungan ini dimulai dari kondisi dasar, yaitu $dp[0] = 1$. Nilai ini mewakili tepat satu cara untuk membuat jumlah 0, yaitu dengan tidak melempar dadu sama sekali, yang menjadi titik awal untuk membangun nilai-nilai berikutnya.

Selanjutnya, untuk mencari cara membentuk jumlah $x$, kita bisa membayangkan nilai lemparan dadu terakhir yang didapatkan. Lemparan terakhir tersebut pasti salah satu dari angka 1 hingga 6. Jika lemparan terakhir bernilai 1, maka sisa jumlah yang harus dibentuk sebelumnya adalah $x - 1$, yang mana banyak caranya adalah $dp[x - 1]$. Jika lemparan terakhir bernilai 2, sisa jumlah sebelumnya adalah $x - 2$ dengan banyak cara $dp[x - 2]$, dan pola ini berlanjut seterusnya hingga angka 6. Karena semua kemungkinan lemparan terakhir ini bersifat independen, kita cukup menjumlahkan semua kemungkinan dari sisa jumlah tersebut.

$$dp[x] = dp[x-1] + dp[x-2] + dp[x-3] + dp[x-4] + dp[x-5] + dp[x-6]$$

Dalam proses perhitungannya, pastikan nilai $x - d \ge 0$. Jika $x - d < 0$, artinya angka dadu $d$ terlalu besar untuk mencapai jumlah $x$, sehingga kondisi tersebut tidak dimasukkan ke dalam perhitungan.

Implementasi strategi penyelesaiannya dilakukan secara bottom-up. kita cukup membuat array $dp$ berukuran $n + 1$ dengan seluruh nilai awal 0 dan mengatur $dp[0] = 1$. Perulangan luar dijalankan dari $i = 1$ sampai $n$ untuk menghitung nilai dari jumlah terkecil ke terbesar. Pendekatan bottom-up ini bekerja karena menjamin bahwa ketika kita sedang menghitung $dp[x]$, semua nilai $dp[x-1]$ hingga $dp[x-6]$ sudah selesai dihitung sebelumnya. kita membangun jawaban untuk nilai $n$ secara bertahap dari kasus-kasus yang lebih kecil tanpa melakukan perhitungan ulang. ## Proof of Correctness
### PoC 1

> [!TIP]
> Buktikan formula solusi tersebut selalu benar untuk masalah ini!


Diberikan sebuah nilai $n \ge 0$. Didefinisikan $S(n)$ sebagai himpunan seluruh urutan lemparan dadu $(d_1, d_2, \dots, d_k)$ sedemikian rupa sehingga:

1. $d_j \in \{1, 2, 3, 4, 5, 6\}$ untuk setiap $j \in \{1, \dots, k\}$
2. $\sum_{j=1}^{k} d_j = n$

Akan dibuktikan bahwa relasi rekurens:


$$dp[n] =  \begin{cases}  1 & \text{jika } n = 0 \\ \sum_{d=1}^{\min(n, 6)} dp[n-d] & \text{jika } n > 0  \end{cases}$$

menghasilkan nilai yang tepat setara dengan $\vert{}S(n)\vert{}$ (banyaknya elemen dalam himpunan $S(n)$) untuk setiap $n \ge 0$.

1. **Base Case (Kasus Dasar)**

	Untuk $n = 0$:
	Himpunan urutan lemparan yang menghasilkan jumlah $0$ adalah himpunan yang hanya berisi satu urutan hampa (urutan dengan panjang $0$):
	
	
	$$S(0) = \{()\}$$
	
	
	Maka, $\vert{}S(0)\vert{} = 1$.
	Berdasarkan definisi $dp[0] = 1$, pernyataan **benar** untuk $n = 0$.

2. **Hipotesis Induksi**

	Asumsikan bahwa relasi rekurens bernilai benar untuk semua bilangan bulat $k$ di mana $0 \le k < n$.
	
	Artinya, untuk setiap $k < n$, nilai $dp[k]$ secara tepat menyatakan banyaknya cara membentuk jumlah $k$ ($dp[k] = \vert{}S(k)\vert{}$).

3. **Langkah Induksi**

	Kita ingin membuktikan bahwa formula tersebut benar untuk nilai $n$ ($dp[n] = \vert{}S(n)\vert{}$).
	
	Tinjau sembarang urutan lemparan $(d_1, d_2, \dots, d_k) \in S(n)$. Elemen terakhir dari urutan ini, yaitu $d_k$, pasti merupakan salah satu nilai mata dadu $d \in \{1, 2, 3, 4, 5, 6\}$ sedemikian hingga $d \le n$.
	
	Kita dapat mempartisi himpunan $S(n)$ menjadi paling banyak 6 sub-himpunan yang saling lepas (*disjoint sets*) berdasarkan nilai lemparan terakhirnya $d$:
	
	
	$$S(n) = \bigcup_{d=1}^{\min(n, 6)} P_d$$
	
	di mana $P_d$ adalah himpunan semua urutan di $S(n)$ yang diakhiri dengan angka $d$:
	
	
	$$P_d = \{ (d_1, d_2, \dots, d_k) \in S(n) \mid d_k = d \}$$
	
	Karena setiap urutan di $S(n)$ pasti memiliki tepat satu nilai lemparan terakhir $d \in \{1, \dots, \min(n, 6)\}$, maka:
	
	1. $P_a \cap P_b = \emptyset$ untuk $a \neq b$ (Saling lepas)
	2. Sesuai Aturan Penjumlahan (*Sum Rule*) dalam kombinatorika:
	
	$$\vert{}S(n)\vert{} = \sum_{d=1}^{\min(n, 6)} \vert{}P_d\vert{}$$
	
	
	
	Sekarang, perhatikan bahwa membuang elemen terakhir $d$ dari sebuah urutan di $P_d$ menghasilkan sebuah urutan baru $(d_1, d_2, \dots, d_{k-1})$ yang jumlah total elemennya adalah $n - d$.
	
	Terdapat hubungan korespondensi satu-satu (*bijeksi*) antara himpunan $P_d$ dengan himpunan $S(n-d)$:
	
	
	$$\vert{}P_d\vert{} = \vert{}S(n-d)\vert{}$$
	
	Dengan menerapkan **Hipotesis Induksi** (karena $n - d < n$, maka $\vert{}S(n-d)\vert{} = dp[n-d]$), kita dapat menggantikan $\vert{}P_d\vert{}$ dengan $dp[n-d]$:
	
	
	$$\vert{}S(n)\vert{} = \sum_{d=1}^{\min(n, 6)} dp[n-d]$$
	
	Persamaan ini persis sama dengan definisi transisi $dp[n]$ pada algoritma.

**Kesimpulan**

Berdasarkan prinsip induksi matematika kuat (*strong induction*), formula transisi $dp[n] = \sum_{d=1}^{\min(n, 6)} dp[n-d]$ terbukti **selalu benar** dan secara tepat menghitung banyaknya cara membentuk jumlah $n$ untuk seluruh $n \ge 0$.

### PoC 2

> [!TIP]
> Jika urutan pembentukan nilai $n$ tidak berpengaruh, misal $2 + 1$ dianggap sama dengan $1 + 2$, apakah formula tersebut tetap sama?


Jika urutan pembentukan nilai $n$ tidak berpengaruh, artinya persoalan ini berubah dari permutasi menjadi kombinasi penjumlahan (*Unbounded Knapsack* atau *Coin Change Problem*). Formula dan struktur iterasi yang digunakan sebelumnya **tidak bisa lagi sama**.

Pada pendekatan sebelumnya, kita menghitung $dp[x]$ dengan mencoba seluruh mata dadu di setiap langkah. Akibatnya, susunan $1 + 2$ terhitung saat evaluasi dadu bernilai 2 setelah 1, dan susunan $2 + 1$ terhitung kembali saat evaluasi dadu bernilai 1 setelah 2. Hal ini menyebabkan terjadinya penghitungan ganda (*double counting*).

Untuk menghindari urutan yang dianggap berbeda, kita harus memaksakan aturan bahwa mata dadu yang dipilih harus diproses secara berurutan, dari nilai 1 hingga 6. Dengan kata lain, kita memproses satu per satu jenis dadu yang tersedia secara global, bukan memilih dadu mana saja di setiap langkah pembentukan $x$.

Definisi state array $dp[x]$ tetap menyatakan banyaknya kombinasi unik untuk membentuk jumlah $x$, dengan base case $dp[0] = 1$. Transisi dasarnya untuk setiap jenis mata dadu $d$ adalah menambahkan cara yang ada sebelumnya dengan cara baru melalui pemakaian dadu tersebut, yaitu $dp[x] = dp[x] + dp[x - d]$.

Perbedaan paling mendasar antara kedua kasus ini sebenarnya terletak pada urutan perulangan (*loop order*).

Pada kasus urutan berpengaruh (permutasi), perulangan nilai target $i$ diletakkan di luar, sedangkan perulangan mata dadu $d$ diletakkan di dalam. Hal ini membuat setiap nilai $i$ bebas memilih mata dadu berapa saja di tahap akhir.

Sebaliknya, pada kasus urutan tidak berpengaruh (kombinasi), perulangan mata dadu $d$ harus diletakkan di luar, dari $d = 1$ sampai $6$, sedangkan perulangan nilai target $i$ diletakkan di dalam, berjalan dari $i = d$ sampai $n$.

Dengan membalik urutan perulangan tersebut, algoritma dipaksa untuk menyelesaikan seluruh kombinasi yang menggunakan dadu bernilai 1 terlebih dahulu ke seluruh isi array. Setelah itu, algoritma baru memperbarui array dengan memperhitungkan kemungkinan penggunaan dadu bernilai 2, lalu dadu bernilai 3, dan seterusnya hingga 6.

Proses ini secara alami mencegah nilai dadu yang lebih kecil muncul setelah nilai dadu yang lebih besar dalam satu susunan kombinasi, sehingga susunan $2 + 1$ tidak akan pernah terhitung jika $1 + 2$ sudah terbentuk.

## Code Implementation

```cpp
#include <iostream>
#include <vector>
using namespace std;

constexpr int M = 1e9 + 7;
auto main() -> int {
    int n;
    cin >> n;
    vector<int> dp(n + 1, 0);

    dp[0] = 1;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= 6; j++) {
            if (i - j >= 0) {
                dp[i] = (dp[i] + dp[i - j]) % M;
            }
        }
    }

    cout << dp[n];
    return 0;
}
```
