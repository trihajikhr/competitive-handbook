# Exponentiation
Pada permasalahan [CSES - Exponentiation](https://cses.fi/problemset/task/1095/), kita diminta untuk mengkalkulasikan hasil dari $a^b \; mod \; 10^9+7$, dengan batasan berupa $0 \le a,b \le 10^9$, dan $1 \le n \le 2 \cdot 10^5$. 

Jika permasalahan ini diselesaikan dengan menggunakan pendekatan yang naif, maka akan dibutuhkan waktu yang sangat lama, bahkan lebih mungkin untuk terkena *Time Limit Exceed*. Ini adalah contoh pendekatan yang mungkin akan kita gunakan, yang jelas-jelas akan terkena *Time Limit Exceed*:

```cpp
#include <iostream>
using namespace std;
 
auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        long long a, b;
        cin >> a >> b;
        long long rest = a;
 
        long long mod = 1e9 + 7;
        for (int i = 0; i < b - 1; i++) {
            rest = (rest * a) % mod;
        }
        cout << rest << "\n";
    }
 
    return 0;
```

Pendekatan diatas memang benar untuk kasus satu test case saja, namun jika ada banyak test case sekaligus, maka dibutuhkan algoritma lanjutan, yaitu trik [Binary Exponentiation](Old%20Mistake/CP-Algorithm%20Site/01-Algebra/01-Fundamentals/01-Binary%20Exponentiation.md). Ini adalah trik untuk menghitung $a^b$ dengan sangat cepat, memanfaatkan operasi biner. Pelajari apa itu Binary Exponentiation terlebih dahulu, sehingga nanti, akan didapatkan jawaban yang benar adalah sebagai berikut:

```cpp
#include <iostream>
using namespace std;
 
constexpr long long MOD = 1e9 + 7;
 
long long binpow(long long a, long long b) {
    long long res = 1;
    while (b > 0) {
        if (b & 1)
            res = (res * a) % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}
 
auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        long long a, b;
        cin >> a >> b;
        cout << binpow(a, b) << "\n";
    }
 
    return 0;
}
```
