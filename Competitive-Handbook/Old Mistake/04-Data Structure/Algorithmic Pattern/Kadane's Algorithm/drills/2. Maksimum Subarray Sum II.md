# Maksimum Subarray Sum II

## Task

Kamu diberikan sebuah array yang berisi $N$ buah integer. Kamu harus memilih sebuah subarray dengan panjang minimal $A$ dan maksimal $B$. Tugasmu adalah mencari nilai maksimum dari jumlah elemen pada subarray tersebut.

### Input

Baris pertama berisi tiga buah integer $N$, $A$, dan $B$.

Baris kedua berisi $N$ buah integer $x_1, x_2, \dots, x_N$.

### Output

Cetak nilai maksimum dari jumlah subarray dengan panjang dalam rentang $[A, B]$.

### Constraints

- $1 \le N \le 2 \cdot 10^5$
- $1 \le A \le B \le N$
- $\vert{}x_i\vert{} \le 10^9$

### Example Input

```
8 2 4
-1 3 -2 5 3 -5 2 2
```

### Example Output

```
9
```

_Catatan: Implementasi Kadane yang kamu buat sebelumnya sudah benar untuk kasus standar subarray tanpa batasan panjang. Untuk variasi ini, kamu perlu memikirkan cara mengoptimasi pencarian prefix sum agar memenuhi batasan panjang subarray yang diminta._

## Jawaban

```cpp
#include <algorithm>
#include <climits>
#include <deque>
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n, a, b;
    cin >> n >> a >> b;
    vector<long long> vec(n);
    for (int i = 0; i < n; i++) {
        cin >> vec[i];
    }

    vector<long long> pref(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        pref[i] = pref[i - 1] + vec[i - 1];
    }

    deque<int> dq;
    long long ans = LLONG_MIN;
    for (int j = a; j <= n; j++) {
        int k = j - a;

        while (!dq.empty() && pref[dq.back()] >= pref[k]) {
            dq.pop_back();
        }
        dq.push_back(k);

        while (!dq.empty() && dq.front() < j - b) {
            dq.pop_front();
        }

        ans = max(ans, pref[j] - pref[dq.front()]);
    }

    cout << ans;

    return 0;
}
```

## Editorial
Untuk menyelesaikan masalah Maksimum Subarray Sum dengan batasan panjang subarray antara $a$ dan $b$, kita perlu mencari nilai maksimum dari selisih dua nilai prefix sum. Jika kita mendefinisikan array `pref` di mana `pref[i]` adalah jumlah elemen dari indeks 0 hingga $i-1$, maka jumlah subarray dari indeks $i$ hingga $j-1$ (dengan panjang $L = j - i$) dapat dihitung sebagai `pref[j] - pref[i]`. Dalam masalah ini, kita ingin memaksimalkan nilai `pref[j] - pref[i]` dengan batasan $a \le j - i \le b$.

Batasan tersebut dapat disusun ulang menjadi $i \le j - a$ dan $i \ge j - b$. Dengan kata lain, untuk setiap titik akhir $j$ yang bergerak dari $a$ hingga $n$, kita perlu mencari nilai `pref[i]` terkecil di dalam jendela indeks $[j - b, j - a]$. Karena kita harus melakukan pencarian ini untuk setiap $j$, melakukan pencarian nilai minimum secara linear di setiap langkah akan menghasilkan kompleksitas $O(n \times (b-a))$, yang mungkin terlalu lambat jika $n$ sangat besar.

Solusi yang jauh lebih efisien adalah menggunakan _Monotonic Queue_ (antrean monotonik) dengan bantuan struktur data `std::deque`. Struktur ini memungkinkan kita untuk menyimpan indeks-indeks yang nilai `pref`-nya berpotensi menjadi minimum. Kita menjaga agar isi deque selalu terurut berdasarkan nilai `pref` secara menaik. Saat kita berpindah ke $j$ berikutnya, kita melakukan tiga langkah utama: pertama, menambahkan indeks baru $k = j - a$ ke dalam deque sambil memastikan deque tetap monotonik dengan menghapus elemen dari belakang yang nilainya lebih besar atau sama dengan `pref[k]`. Kedua, membuang elemen dari depan deque yang sudah tidak relevan karena posisinya berada di luar batas jendela kiri, yaitu indeks yang lebih kecil dari $j - b$. Ketiga, nilai `pref[j] - pref[front]` akan menjadi kandidat jawaban terbaik untuk posisi $j$ tersebut karena `front` dari deque selalu merupakan indeks dengan nilai `pref` terkecil dalam rentang yang diizinkan.

Implementasi ini memiliki kompleksitas waktu $O(n)$ karena setiap elemen di dalam array hanya akan dimasukkan ke dalam dan dikeluarkan dari deque tepat satu kali selama proses perulangan. Penggunaan `long long` sangat penting untuk menghindari _overflow_ pada variabel yang menyimpan jumlah total elemen jika nilai input cukup besar. Dengan memastikan sinkronisasi I/O yang tepat `std::ios_base::sync_with_stdio(false)`, kode akan berjalan dengan sangat cepat dan mampu menangani batasan kendala yang ketat. Teknik ini adalah aplikasi klasik dari _sliding window minimum_ yang dikombinasikan dengan _prefix sum_, yang sangat berguna dalam berbagai variasi soal pemrograman kompetitif lainnya.
