# Dokumentasi PBDS (Policy-Based Data Structures) C++

## Daftar Header Wajib

Berbeda dengan kontainer Standard Template Library (STL) biasa yang hanya memerlukan header standar seperti `<set>` atau `<map>`, Policy-Based Data Structures (PBDS) memerlukan header khusus dari ekstensi GNU C++. Di dalam struktur direktori GCC, pustaka ini berada di bawah namespace `__gnu_pbds`. 

Untuk menggunakan struktur data berbasis *tree* (seperti `tree`), kita memerlukan dua header utama:

```cpp
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>
```


Sedangkan untuk menggunakan struktur data berbasis _hash table_ (seperti `gp_hash_table` atau `cc_hash_table`), header yang wajib disertakan adalah

```cpp
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/hash_policy.hpp>
```

Jika Anda ingin menggunakan priority queue atau heap alternatif yang disediakan oleh PBDS, header yang diperlukan adalah:

```cpp
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/priority_queue_tag.hpp>
```

Dalam praktiknya di _competitive programming_, seringkali peserta menyertakan seluruh header ekstensi atau langsung menyertakan header asosiatif umum beserta _policy_ spesifik yang dibutuhkan agar aman dari kesalahan _compilation error_.

## Namespace (`__gnu_pbds`) dan Aliases yang Sering Digunakan

Seluruh komponen PBDS berada di dalam namespace `__gnu_pbds`. Mengetik nama namespace ini secara berulang kali pada setiap deklarasi struktur data akan membuat kode menjadi panjang dan kurang rapi. Oleh karena itu, _typedef_ atau _using alias_ sangat dianjurkan.

### Namespace Declaration

Anda dapat mendeklarasikan penggunaan namespace secara lokal di dalam fungsi atau global (namun berhati-hatilah terhadap potensi konflik nama dengan namespace `std`):

```cpp
using namespace __gnu_pbds;
```

### Rekomendasi Alias untuk Ordered Set

Deklarasi lengkap dari `tree` di PBDS memerlukan lima parameter _template_. Menulis ulang parameter tersebut setiap kali membuat set terurut sangat tidak efisien. Berikut adalah alias standar yang bersih dan modular:


```cpp
#include <iostream>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;
using namespace __gnu_pbds;

// Mendefinisikan ordered_set dengan tipe data generic (default: int)
template <typename T>
using ordered_set = tree<
    T, 
    null_type, 
    less<T>, 
    rb_tree_tag, 
    tree_order_statistics_node_update
>;
```

Penjelasan singkat mengenai parameter template di atas yang akan dibahas mendalam pada nomor 3:

1. `T`: Tipe data elemen yang disimpan (misalnya `int`, `long long`, atau `pair<int,int>`).
    
2. `null_type`: Menandakan bahwa struktur ini adalah _set_ (hanya menyimpan kunci, bukan pasangan _key-value_). Untuk _map_, posisi ini diganti dengan tipe data _mapped value_.
    
3. `less<T>`: Fungsi pembanding (_comparator_) untuk menentukan urutan elemen (bisa diganti `less_equal` dengan catatan khusus atau `greater<T>`).
    
4. `rb_tree_tag`: Menentukan jenis _underlying data structure_ berupa Red-Black Tree.
    
5. `tree_order_statistics_node_update`: Kebijakan pembaruan _node_ yang memberikan kemampuan _order statistics_ (`find_by_order` dan `order_of_key`).

## Template Dasar untuk Memulai Kode

Berikut adalah kerangka kerja (_boilerplate_) standar yang bersih, rapi, dan siap digunakan untuk _competitive programming_ yang memanfaatkan PBDS:

```cpp
#pragma GCC optimize("O3")
#pragma GCC target("avx2,bmi,bmi2,lzcnt,popcnt")

#include <bits/stdc++.h>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;
using namespace __gnu_pbds;

// Template untuk Ordered Set (Ascending)
template <typename T>
using ordered_set = tree<T, null_type, less<T>, rb_tree_tag, tree_order_statistics_node_update>;

// Template untuk Ordered Multiset (Memperbolehkan duplikat dengan menggunakan less_equal)
// Catatan: Operasi erase pada ordered_multiset dengan less_equal memerlukan penanganan khusus pada iterator.
template <typename T>
using ordered_multiset = tree<T, null_type, less_equal<T>, rb_tree_tag, tree_order_statistics_node_update>;

void solve() {
    // Contoh Inisialisasi
    ordered_set<int> os;
    os.insert(10);
    os.insert(5);
    os.insert(20);

    // Menguji order statistics
    // Mencari elemen pada indeks ke-1 (0-indexed) -> 10
    auto it = os.find_by_order(1);
    if (it != os.end()) {
        cout << "Elemen pada indeks 1: " << *it << "\\n";
    }

    // Mencari jumlah elemen yang strictly less than 10 -> 1 (yaitu angka 5)
    int strictly_less = os.order_of_key(10);
    cout << "Jumlah elemen < 10: " << strictly_less << "\\n";
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int t = 1;
    // cin >> t;
    while (t--) {
        solve();
    }
    
    return 0;
}
```

## Catatan Kompatibilitas dan Penggunaan Header

- **GCC Extension:** Pustaka `<ext/pb_ds/...>` adalah bagian dari GNU C++ Standard Library. Pustaka ini dijamin berjalan dengan sempurna pada platform _competitive programming_ seperti Codeforces, AtCoder, CodeChef, dan TLX Toki yang menggunakan compiler GCC/G++.
    
- **MSVC / Clang:** Jika Anda mencoba mengompilasi kode ini menggunakan compiler Microsoft Visual C++ (MSVC) secara lokal di Windows, header ekstensi GNU ini tidak akan ditemukan karena bersifat non-standar ISO C++. Sebagai alternatif lokal, Anda dapat menggunakan MinGW-w64 atau WSL (Windows Subsystem for Linux) bagi pengguna Windows.
