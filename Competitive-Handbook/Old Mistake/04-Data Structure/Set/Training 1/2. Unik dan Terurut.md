# Unik dan Terurut (Unique and Sorted Elements)

## Task

Diberikan sebuah barisan yang terdiri dari $N$ buah integer. Kamu harus memproses $Q$ buah operasi yang berkaitan dengan kumpulan data (set). Operasi tersebut dibagi menjadi dua jenis:

1. **`1 x`**: Menambahkan elemen $x$ ke dalam kumpulan data. Jika elemen tersebut sudah ada, kumpulan data tidak berubah.
    
2. **`2 x`**: Memeriksa apakah elemen $x$ ada di dalam kumpulan data. Cetak `YA` jika ada, atau `TIDAK` jika tidak ada.

Tugas kamu adalah mengeksekusi semua operasi tersebut secara berurutan dan mencetak hasil dari setiap operasi jenis kedua.

### Input

Baris pertama berisi sebuah integer $N$ yang menyatakan jumlah elemen awal dalam kumpulan data.

Baris kedua berisi $N$ buah integer awal yang dimasukkan ke dalam kumpulan data.

Baris ketiga berisi sebuah integer $Q$ yang menyatakan jumlah operasi.

$Q$ baris berikutnya masing-masing berisi sebuah string atau angka operasi dengan format `1 x` atau `2 x`.

### Output

Untuk setiap operasi jenis kedua (`2 x`), cetak `YA` jika elemen $x$ ada di dalam kumpulan data, atau `TIDAK` jika tidak ada. Setiap jawaban dicetak pada baris baru.

### Constraints

- $1 \le N, Q \le 2 \cdot 10^5$
    
- $-10^9 \le x \le 10^9$
    
- Elemen awal pada kumpulan data juga berada dalam rentang $-10^9$ hingga $10^9$.
    

### Example Input

```
3
1 2 3
4
2 2
1 4
2 4
2 5
```

### Example Output

```
YA
YA
TIDAK
```

## Editorial
Permasalahan ini sangat tepat jika diselesaikan menggunakan struktur data `std::set` karena secara otomatis mampu menyimpan elemen unik dan terurut sekaligus. Kita bisa memanfaatkan fungsi `insert()` untuk menambahkan elemen baru serta fungsi `count()` untuk memeriksa keberadaan suatu elemen, di mana fungsi tersebut akan mengembalikan nilai $1$ jika elemen ditemukan dan $0$ jika tidak ada. Mengingat struktur data ini berbasis _balanced binary search tree_ (biasanya _Red-Black Tree_ di STL C++), kompleksitas waktu untuk operasi penyisipan maupun pencarian tergolong sangat efisien, yakni $O(\log N)$ per operasi, sehingga dijamin aman untuk batasan $N$ dan $Q$ hingga $2 \cdot 10^5$.

Sebagai pendalaman materi untuk memperkuat pemahaman mengenai `std::set`, penting untuk mengetahui karakteristik internal dan fungsi pendukung lainnya yang sering digunakan dalam kompetisi pemrograman. Pertama, karena elemen di dalam `set` selalu terurut, kita bisa memanfaatkan fungsi anggota seperti `lower_bound(x)` dan `upper_bound(x)` untuk mencari batas nilai secara cepat dalam waktu $O(\log N)$, misalnya untuk mencari elemen terkecil yang lebih besar atau sama dengan $x$. Kedua, jika kita hanya ingin mengecek keberadaan elemen tanpa harus memanggil `count()`, fungsi `find(x)` adalah alternatif yang sering dipakai karena mengembalikan iterator ke elemen tersebut atau mengembalikan `end()` jika elemen tidak ditemukan. Terakhir, perlu diingat bahwa iterasi atau akses elemen berdasarkan indeks (seperti `s[i]`) tidak didukung secara langsung dalam waktu $O(1)$ karena `set` bukanlah struktur data linier seperti `vector`, melainkan struktur berbasis _tree_, sehingga jika kita membutuhkan operasi berbasis indeks yang tetap terurut, struktur data alternatif seperti _Policy-Based Data Structures_  `gnu_cxx::tree` atau _Fenwick Tree/Segment Tree_ dengan teknik _coordinate compression_ perlu dipertimbangkan.

## Jawaban

```cpp
#include <iostream>
#include <set>
using namespace std;

auto main() -> int {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n;
    cin >> n;
    set<int> daset;
    for (int i = 0, x; i < n; i++) {
        cin >> x;
        daset.insert(x);
    }

    int q;
    cin >> q;
    while (q--) {
        int a, b;
        cin >> a >> b;
        if (a == 1) {
            daset.insert(b);
        } else if (a == 2) {
            cout << (daset.count(b) ? "YA" : "TIDAK") << "\n";
        }
    }

    return 0;
}
```
