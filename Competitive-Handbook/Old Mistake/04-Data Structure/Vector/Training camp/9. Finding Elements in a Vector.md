# Finding Elements in a Vector

## Task

Kamu diberikan sebuah `vector` yang berisi $N$ buah integer. Kamu harus memproses $Q$ buah _query_, di mana setiap _query_ berisi sebuah integer $x$. Tugas kamu adalah mencari tahu apakah nilai $x$ tersebut ada di dalam `vector`. Jika ditemukan, cetak indeks kemunculan **pertama** dari $x$ (menggunakan indeks berbasis 0). Jika tidak ditemukan, cetak `-1`.

### Input

Baris pertama berisi dua buah integer $N$ dan $Q$.

Baris kedua berisi $N$ buah integer yang dipisahkan oleh spasi untuk mengisi `vector`.

$Q$ baris berikutnya masing-masing berisi sebuah integer $x$ yang ingin dicari.

### Output

Untuk setiap _query_, cetak indeks kemunculan pertama dari $x$ jika ada, atau `-1` jika tidak ada. Setiap hasil dicetak pada baris baru.

### Constraints

- $1 \le N, Q \le 10^3$
    
- Nilai setiap elemen di dalam `vector` dan nilai $x$ berada dalam rentang $[-10^9, 10^9]$.
    

### Example Input


```
5 3
10 20 30 20 50
20
40
10
```

### Example Output


```
1
-1
0
```

## Jawaban

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    int n, q;
    cin >> n >> q;
    vector<int> vec(n);
    for (auto& x : vec) {
        cin >> x;
    }

    while (q--) {
        int t;
        cin >> t;
        auto idx = find(vec.begin(), vec.end(), t);
        if (idx == vec.end()) {
            cout << -1 << "\n";
        } else {
            cout << idx - vec.begin() << "\n";
        }
    }

    return 0;
}
```
