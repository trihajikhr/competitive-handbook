# 2D Vector Basics (Grid Initialization)

## Task

Kamu diberikan koordinat sebuah grid berukuran $R \times C$ (baris $\times$ kolom). Tugas kamu adalah membuat sebuah `vector` dua dimensi (`vector<vector<int>>`) untuk merepresentasikan grid tersebut, menginisialisasi semua elemen di dalamnya dengan nilai $X$, lalu mencetak isi dari grid tersebut.

### Input

Baris pertama berisi tiga buah integer $R$, $C$, dan $X$, yang masing-masing menyatakan jumlah baris, jumlah kolom, dan nilai awal pengisian elemen.

### Output

Cetak $R$ buah baris, di mana setiap baris berisi $C$ buah integer yang dipisahkan oleh spasi, sesuai dengan isi grid yang telah dibuat.

### Constraints

- $1 \le R, C \le 500$
    
- $-10^9 \le X \le 10^9$
    

### Example Input

Plaintext

```
3 4 7
```

### Example Output

Plaintext

```
7 7 7 7
7 7 7 7
7 7 7 7
```

Silakan kirimkan solusi kode kamu untuk Soal 11!

## Jawaban

```cpp
#include <iostream>
#include <vector>
using namespace std;

auto main() -> int {
    int r, c, x;
    cin >> r >> c >> x;

    vector<vector<int>> grid(r, vector<int>(c, x));
    for (const auto& row : grid) {
        for (const auto& t : row) {
            cout << t << " ";
        }
        cout << "\n";
    }

    return 0;
}
```
